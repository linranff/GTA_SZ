# Asset sources

Street, buildings, furniture, bicycle and character meshes: original project geometry authored through Blender. Editable source: `artifacts/game/shenchengji-assets.blend`.

Ceramic, road and paving textures and shop sign raster artwork: original procedural project assets. Shop text was rasterized using the local macOS Arial Unicode font; the font file itself is not distributed.

Additional plaster and wood material maps: **Powered by Poly Haven**.

- Plastered Wall 05: https://polyhaven.com/a/plastered_wall_05
- Wood Table 001: https://polyhaven.com/a/wood_table_001
- License: CC0-1.0, https://polyhaven.com/license
- Download URLs and hashes: `textures/polyhaven/manifest.json`.

The game does not use a live asset API. Concept illustrations are not used as fake interactive scenery. The pilot street is a fictional Longhua-inspired composition, not a measured reconstruction of a specific street. Existing OSM/Overture data have their own attribution in the project's `data/ATTRIBUTION.md` and are not embedded in this pilot mesh.

Babylon.js / loaders: Apache-2.0. Runtime npm dependency versions are pinned in `package-lock.json`.
