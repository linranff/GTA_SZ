# 深城纪：下班以后 · 可玩开发版 0.1

2026-09-05。此文记录实际做出的内容；目标策划仍在 `游戏策划与美术方向-v1.md`。这是第一个可玩片段，画面距离目标概念图仍有明显差距，尤其是角色、街区变化与自然光照；不能称为最终美术。

## 运行

项目根目录执行：

```sh
npm install
npm run dev
```

开发地址通常是 `http://127.0.0.1:5173/`，以终端显示为准。
生产构建：`npm run build`；预览：`npm run preview -- --port 4173`。
目前仅在本机启动，没有部署到公网或发布 Steam。

## 已实现的连续体验

1. 标题菜单后进入第三人称街道，WASD / 方向键移动、Shift 快走、拖动鼠标转镜头。
2. 靠近顺成仓配的何志，E 接活；看到基础报酬、质量奖励与当日成本。
3. 读标签，用 1 / 2 / 3 分拣九件包裹。失误影响质量奖励，不扣基础工资。
4. 推车经过三个路线点，在巷尾 E 结算。没有完成路线不能领奖，已结算的班次不能重复领钱。
5. 去旧物店买雨衣、床垫或通勤车。余额不足与已经拥有时禁止重复购买。
6. 床垫升级在房间中显示床品、灯、椅子与植物。通勤车购入后 B 切换骑行速度和可见自行车；骑行动画目前仍是基础实现，尚非完整自行车物理。
7. 与林夏选择一起吃饭或独自回家，朋友关系只增加一次；本片段还没有完整恋爱系统。
8. 回到青禾公寓看房间，休息后进入下一天，保留存款、物品与关系。
9. IndexedDB 自动保存，可刷新后继续；Esc 暂停、Tab 手账、P 查看实际 FPS。页面切到后台会暂停并保存。

## 实际资产

- 约 100 米虚构青禾巷，18 栋模块化建筑，包含街道两侧与远端收口建筑。
- 窗洞与窗框、防盗网、阳台、空调及支架、落水管、底层店面、中文招牌和雨棚都有几何结构。没有以整块方盒替代可见建筑。
- 街道路面、路沿、排水口、自行车、餐桌、板凳、绿化、路灯、垃圾桶与运货手推车。
- 可编辑的陈野和林夏模型、基本关节摆动，以及少量街道居民。
- 一间出租屋及独立升级物件。室内当前采用固定观察相机与交互入口，尚未开放自由室内行走。
- Blender 源文件：`artifacts/game/shenchengji-assets.blend`。导出的 GLB 在 `public/assets/`，源脚本为 `scripts/build_game_assets.py`。
- 资产量与来源见 `public/assets/asset-manifest.json`、`public/assets/ATTRIBUTION.md`。额外墙面和木材 PBR 贴图为 Poly Haven CC0；原始链接和哈希已保存。

采用 Blender 建模与 GLB 导出，Babylon.js / TypeScript 实时运行。街道按材质合并网格，避免数千个独立部件分别提交绘制。材质含颜色、法线和粗糙度，光照含环境光、方向光、PCF 阴影及半分辨率 SSAO。此小片段目前整体加载，不把它描述为已完成全城流式加载或 LOD 系统。

## 验证依据

- `npm test`：五项游戏状态测试，覆盖到账一次性、费用、购买与重复购买、失误工资、部分工作恢复、异常存档和关系奖励防重复。
- `npm run build`：TypeScript 检查与 Vite 生产构建。
- 已解决一次只在生产包出现的加载死锁：材质适配模块回引入口共享代码时，与入口顶层 `await` 相互等待。启动流程改为不阻塞模块求值的异步函数，并在生产地址重新跑通完整玩法。
- `scripts/playthrough.mjs`：使用 Chrome 的真实键盘/按钮输入完成一整段流程，未用传送或改钱接口替代游玩；结果在 `artifacts/game/playthrough.json`。
- `scripts/benchmark.mjs`：在 1920×1080 生产构建上连续往返行走五分钟，NPC、HUD、自动存档、阴影和 SSAO 保持运行；结果在 `artifacts/game/performance-1080p.json`。测试结束前不能把这个路径当作已通过证明。
- 该性能测试使用本机 Chrome 的无头模式、Apple M1 Max Metal GPU。它不是 Safari 或 Windows 兼容性测试，也不代表在所有设备、所有浏览器下均达到相同帧率。

执行截图在 `artifacts/game/`；它们是网页真实渲染结果。旧的 `output/art-direction/` 仍是概念图，不与实机混淆。

## 本轮实测结果

最终生产构建在本机 Apple M1 Max / Chrome 152 无头模式中，以 1920×1080 连续往返行走 300 秒。预热与起始 120 帧排除后统计 17,880 帧：

| 指标 | 实测 |
|---|---:|
| 平均帧率 | 60.00 fps |
| p50 帧时间 | 16.70 ms |
| p95 帧时间 | 17.50 ms |
| p99 帧时间 | 18.10 ms |
| >50ms 帧数 | 0 |
| 浏览器运行/加载错误 | 0 |

通过本项目此前定义的 60fps 附近验收门槛。不是逐帧都 ≤16.67ms 的承诺；不是 Safari、Windows 或完整未来城市的性能证明。测试场景包含移动 NPC、HUD、自动存档、PCF 阴影与 SSAO；不包含完整车流或尚未开发的地图。

六个 GLB 约 23.67 MB，纹理已嵌入；生产入口 JS 本次本机传输约 1.38 MB。源文件和构建的 SHA-256 记录在 `artifacts/game/tested-build.json`。构建仍有一个关于大 JS chunk 的提示，后续可以继续拆分加载；当前启动与可玩流程已验证。

截图入口：`artifacts/game/street-1080p.png`、`artifacts/game/room-upgraded.png`、`artifacts/game/payout.png`。完整生产包流程已验证至第二天：余额 133，持有床垫，朋友关系 1，下一班次正常开放。

## 与完整目标的差距

当前能验证小范围行走与打工生活循环。尚未做到概念图级写实、当前深圳具体街道的精确复刻、深圳湾可玩区域、完整恋爱与职业章节、交通车流、成熟人物动作和全城内容。

下一轮的美术工作应集中在一处可近看的店面与人物：更准确的建筑比例、店内陈设、门窗层次、织物与皮肤、成组自然植物、分区烘焙光照。先在同机位实机截图中取得明显改善，再扩展区域；不以增加方块建筑或仅修改概念图来代替游戏美术进展。
