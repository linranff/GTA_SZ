# 深圳湾首段：600 米滨海骑行道候选

> 当前作为滨海场景的数据与资产参考保留。首个网页可玩片段已调整为城中村日结下班生活，详见《游戏策划与美术方向-v1.md》。资产通过 GLB/glTF 导入网页；下文 UE 描述为早期记录。

## 已确定的空间依据

- 地图路径：OSM `way/255653770`，原始标签为 `highway=cycleway`，`bicycle=designated`，`foot=designated`，`segregated=no`，`surface=paving_stones`，`source=GPS`。
- 定位锚点：OSM `way/1194924337`（深圳湾公园站建筑记录）。
- 选段：沿原始路径桩号约 1169.2 米起，长度 600 米；不是官方命名路线。
- 路线 GeoJSON：`data/processed/shenzhen_bay/pilot_route.geojson`。
- 此处的地面材质标签和通行标签没有现场复核；不把它们当作 2026 年现场实测。

## 第一轮建模范围

先精修其中 60–100 米可近看的连续镜头区，再沿路线扩展。
游戏场景中的建筑只有在外形与立面有足够参考时才进入可渲染资产层。

| 资产 | 制作内容 | 还缺的参考 |
|---|---|---|
| 园路 | 真实中心线、铺装接缝、边缘收口、路沿、排水 | 当前净宽、横坡、铺装样式和尺寸 |
| 海堤与亲水边界 | 实际岸线变化、挡墙结构、转折处、近看材质 | 海堤断面、顶标高、栏杆实际形式 |
| 坐凳与休憩点 | 木/金属/石材结构、倒角、连接件、接地 | 本段实际款式、位置和尺寸 |
| 路灯与标识 | 灯杆结构、底座、灯头、牌面层次 | 本段灯具照片、间距、标识现状 |
| 主要植被 | 树干、分枝、叶冠、地被组合与实例变化 | 实际树种、尺度与种植带边界 |
| 可见关键建筑 | 准确轮廓、分段体量、幕墙分格、底层入口 | 立面、已核实高度、观察方向 |
| 骑行交互 | 角色视高、转向、辅助平衡、碰撞和上下车 | 完成实际路面后调整手感 |

地图参考文件只包含来源曲线：非渲染，不是方块建筑，也不是成品场景。
每个成品资产同时交付 UV、可移植材质贴图、LOD 和简单碰撞。Blender 程序材质需要烘焙或在 UE 重建后才算导入完成。

## 验收

1. 现场参考与模型能通过相同机位对照，未知部分在资产记录中保留。
2. 步行视高近看边角、接缝、基座不能只有平面纹理假细节。
3. 沿路径骑行能连续通过，路沿、栏杆与建筑入口的碰撞合理。
4. M1 Max 上用普通网格和 LOD 验证，不能只在 Blender 离线渲染中好看。
5. 地图、精细模型、游戏碰撞、导航分别验收，不把完成其中一项等同于完成游戏。
