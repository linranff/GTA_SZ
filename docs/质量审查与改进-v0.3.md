# 深城纪 v0.3：质量审查与改进

2026-09-05。范围是当前浏览器城市驾驶原型，验收依据为实际加载的 GLB、正常输入流程、截图和帧时间。目标是写实、轻微赛博朋克的深圳黄昏，仍未达到最终概念图质量。

## 最高优先级：影响正确性与体验的缺陷

| 问题 | 原因与影响 | 本轮处理 / 验证入口 |
|---|---|---|
| 陆地远景变成海面、地面闪烁 | 全城下方铺设同一张水面，近裁剪面过小；远景深度精度不足时水面盖过陆地。道路重复共面网格也会闪。 | 海/陆网格按海岸线互斥裁切；道路先做平面合并；相机按驾驶/近处看车/远景调整 near plane，标线使用深度偏移。具名地标反向观景复检。 |
| 机动车道出现树 | 行道树仅针对其来源道路定位，可能侵入旁边车道；初次清理仅考虑树干，未考虑完整树冠。 | 离线检查全部道路缓冲区，按树冠半径外加 1 米清理；运行时再做一次所有相邻路段检查。`street-validation.json` 保留数量。 |
| 车流位置错、开场逆行车辆 | 克隆车辆继承玩家父节点，重复变换；无向道路图让环境车辆任意倒向。 | 独立父节点、统一坐标、按 OSM 单向标记约束环境车下一段方向；恢复附近车流。仍不是完整交通仿真。 |
| 改动看似成功、实际加载旧资产 | 多个建模入口与增量替换可能互相覆盖，构建成功不能证明视觉成功。 | 保存压缩后字节数和 SHA-256；普通楼体排除重点对象 ID，增量校验排除清单；正式测试使用生产构建。 |
| 细节增长拖垮浏览器 | 把每栋阳台和栏杆都常驻显示，会快速增加三角面与绘制成本。 | 精细立面拆为 150 个 640 米网络分区，按附近预取、按距离卸载；基础楼体/道路尚未分块。复用车辆和行人 GPU 实例缓冲，停止隐藏页面及初始化中的场景渲染。 |

## 画面不足与本轮修正

- 暗面失去材质：提高冷色天空漫反射、环境反射亮度，给近处车辆柔和补光；没有把所有东西统一加曝光。
- 指示牌出现白色光团：关闭路牌镜面高光，保留可读的漫反射与低强度自发光。
- 海面出现车灯大光斑：海面明确排除车辆聚光灯，只接受天空、太阳及环境反射。
- 窗户像黄块：使用无损发光贴图、窗框与窗帘暗部，HDR 发光配合柔和 Bloom；附近补充有限的窗光照明。
- 材质趋同：办公室/住宅/石材配色组；逐栋配色源数据未完整导出到 GLB，此项仍在修复。近处增加实体幕墙竖梃、阳台、栏杆和临街檐口。普通楼体仍是艺术化外立面，不能当作逐栋实测复刻。
- 车体廉价与漆面过黑：重建曲面、真实轮拱开口、连续饰条、轮辐、刹车盘/卡钳、灯组、门缝；修正车体法线和灯组遮挡。现为约 3.4 万三角面的独立模型。
- 近处树冠、路口标线、海岸植物密度和灯具布置仍需逐街区人工视觉整理。

车辆是参考 SU7 比例的独立外观习作，靛蓝为本项目选择的车漆，不宣称是官方精确色号或授权车型。尺寸参考：[小米官方 SU7 参数表](https://s1.xiaomiev.com/activity-outer-assets/0328/env/SU7%E5%8F%82%E6%95%B0%E9%85%8D%E7%BD%AE%E8%A1%A8328.pdf)。

## 内容补充

当前驾驶只有观光，缺少角色、目标和回报。这是产品层面的核心不足。本轮加入三段虚构人物的“下班顺路”行程：城市工人、年轻职场人、日结打工者。完整结构为接单 → 驾车接人 → 停车交谈 → 行驶送达 → 收入与房间基金进度 → 本地保存。结算只能领取一次，调试跳转不会伪造行程收益。

这只是最小生活玩法，不等于已经完成职业、恋爱、住房与经济系统。下一阶段应优先制作一个街区的室外人物互动和连续故事，而不是无差别扩地图。

## 开发便利

- M：点击地图任意位置，吸附到附近车道并跳转。地点列表仍有导航、快速前往与观景。
- G：高空全景，拖动旋转、滚轮升降，再按 G 返回驾驶。
- V：近处查看车辆，拖动环绕、滚轮缩放；F 返回。
- J：城市手账与人物行程；E 在停稳后接人/送达。
- P：实际帧率。测试同时记录原始帧时间，不用面板瞬时数字证明稳定 60fps。

## 尚未解决的主要限制

1. 除莲花山增量山路外，路网高架/隧道仍压平；路口车道连接、灯控与让行不完整。这是长距离驾驶可信度的首要后续工作。
2. 通用楼体、车模型、人物与植物距离高质量商业作品仍有差距。重点对象精度以来源清单为准；看起来像地标不等于所有尺寸和立面已测量。
3. 精细立面已有真实分块下载/卸载；基础楼体、道路尚未分块，仍需几何 LOD 和完整 GPU 内存预算。
4. 车辆悬挂、碰撞形状、交通 AI、人物动画仍简化；没有下车探索、完整职业和社交系统。
5. 城市边缘、地形与实景坐标有压缩和艺术化接合；深圳行政区全境并未重建。
6. 目前验证以本机 Chrome/WebGL2 为主；不能由此推导 Safari、Windows、Steam 版本性能。

具体验证数值记录在 `artifacts/city/`，最终性能需以最新一轮报告为准。
