# 高大林冠层：六种 10–30 m 的树 · 2026-09-17

## 问题

此前的植被只有 8 m 左右的榕树 / 棕榈 / 羊蹄甲原型（`public/city/landscape/`），加上贴近地面才可见的
草叶（`city-meadow.ts`，2304 簇 / 80,640 三角面）。从无人机或 G 键俯瞰时，莲花山、人才公园、深圳湾公园等
大片绿地只剩一层草坪贴图，城市"光秃秃"；沿滨海大道、深南大道开车时路边也没有能压住天际线的树。

## 做法

新增独立的林冠层，与原有 8 m 植被并存，不改 `planting.json` 及其哈希。

| 层 | 文件 | 说明 |
| --- | --- | --- |
| 建模 | `scripts/build_canopy_trees.py`（Blender） | 六种常见深圳树种的程序化研究，不是扫描：巨榕 30 m（板根 + 气根柱）、木棉 24 m（分层平展枝）、樟树 18 m（宽圆冠）、小叶榄仁 15 m（塔形分层）、凤凰木 12 m（扁伞冠 + 橙红花团）、芒果 11 m（低圆密冠）。树冠是实心低模团块，无 alpha 卡片、无透明叠绘。每种 3 级 LOD：全模 1.9–4.0k、中模 0.5–1.7k、远模 80 三角面；18 个 GLB 共 713 KB。 |
| 颜色 | 同上 | 六种受光绿 + 各自的阴面色 + 远模中间色；受光色刻意低于草坪反照率，俯瞰时树比草坪深。运行时再叠每株的冷暖色偏移。 |
| 布点 | `scripts/build_canopy_trees.py --prepare`（shapely） | 三类来源：公园多边形按面积投点（≈1 株 / 520 m²，小于 1.2 ha 的口袋公园不种巨榕）、街区间空地草坪（离建筑 ≥ 9 m）、trunk/primary 道路两侧行道树（每条路一个树种，等距成排）。 |
| 校验 | `artifacts/city/canopy-trees/placement-validation.json` | 序列化后逐株复核：树干在陆地上、距任何车行道 ≥ 3.2 m、距原有树干 ≥ 2.6 m；树冠圆（+1 m）不进任何建筑、地标碰撞轮廓、地标 `excludeRadius` 圆和驿站地块；冠心不进水面。树冠允许伸到路面上方，允许相互交叠到半径和的 0.62。 |
| 运行时 | `src/city-canopy.ts` | 100 m 网格；thin instances；街景 <170 m 全模、<650 m 中模、其余远模；俯瞰只用中模（<520 m）和远模。预算见 `city-graphics-quality.ts` 的 `canopy*` 字段，超预算按距离降级而非消失。树干取周围 3 个采样点的最低地面高度，坡地不悬空。街景阴影只投全模 + 中模，俯瞰投中模 + 远模。 |

`configureRoadside` 的 `blocked` 回调现在也查林冠树干（`trunkNear`），运行时补种的路边小树不会和行道树同根。

同时把近地草叶预算减半（`meadowClumps`：高 / 中 1024、低 512，原 2304），驾驶视角草叶三角面从约 80k 降到约 36k。

## 结果

布点：45,626 株（公园 24,615 / 空地 12,759 / 行道 8,262）；巨榕 1,166、木棉 6,008、樟 7,932、榄仁 11,702、凤凰木 7,073、芒果 11,745。

同机位、`quality=high`、1600×900、headless Chrome（ANGLE Metal）——绝对帧率仅供相对比较：

| 人才公园俯瞰 1100 m | 23.4 | 36.5 | 0 / 320 / 5553 | 762k |
| 全城俯瞰 3000 m | 31.3 | 50.0 | 0 / 320 / 6000 | 786k |

"之前"是同一台机器在上一次运行里测的，帧率差异主要来自着色器缓存与浮动，不是林冠让渲染更快；
同一页面内的 A/B（隐藏林冠网格）显示林冠本身的开销约 1–5 fps，主要在阴影通道（深圳湾公园密林 43.2 → 48.6，
滨海大道 56.1 → 60，福田 CBD 58.4 → 59.6）。

## 已知限制

- 树种形态是艺术化研究；数量与位置来自 OSM 公园 / 道路，不是植被普查。
- 运行时不做树干碰撞（与原有 8 m 植被一致）；树干距车行道 ≥ 3.2 m，正常行驶不会撞到。
- 远模是单团块，>650 m 处切换时轮廓略有变化；远模包络已缩到全模的 0.87 以减轻"变大"感。
- Vite 开发服务器启动时索引 `public/`，且监听器忽略 `*.glb`；新增 GLB 后需重启 `npm run dev`，否则返回 index.html（GTA_SZ#4 修复的副作用，已写在 `vite.config.ts`）。
