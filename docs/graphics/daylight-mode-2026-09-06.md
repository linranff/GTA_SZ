# 雨后晴昼：第三套城市光影

2026-09-06 后续更新：当前已换用 Rustig Koppie (Pure Sky)，以清蓝天空和稀疏薄云为主，原始 HDR 为 15,257,521 字节。下文保留首次第三模式接线说明；最新来源、太阳方向及实机复核见 `data/materials/daylight-environment.json` 与 `coastal-sky-2026-09-06.md`。

保留红霞日落和月色夜景，新增蓝天、白色积云和暖白日光。可见天空与玻璃、车漆的环境反射共享同一份线性 HDR；没有把反射源换成纯蓝色，也没有通过提高全局雾量遮盖远景。

## 接线

`src/city-cinematic.ts` 返回 `setMode('sunset' | 'night' | 'day')`。原 `setNight(true)` 和 `setNight(false)` 分别保持夜晚、日落语义。`src/city-daylight.ts` 导出类型、中文标签和 `nextCinematicLightingMode()`。

世界控制器应统一传递模式，避免先设置白天后再调用 `setNight(false)` 将它覆盖为日落。日光模式关闭公共照明漫反射场和路灯显著自发光；建筑内部零星灯光可以保留，但街区不可照成夜景。HUD 应显示白天时间和模式中文名。

## 光照

- 太阳来自 HDR 的太阳像素方向，使用环境旋转的逆矩阵转换到场景，保持阴影与高光方向一致。
- 1024 像素立方体在加载期间生成及预滤一次；基础层作为清晰天空，预滤层用于不同粗糙度反射。控制器等待加载完成或明确失败再返回。
- 日光暖白、半球补光浅蓝；降低半球补光和 bloom，保留立面转折、树木阴影和湿地高光。
- 晴天远雾更浅、更稀，较少侵蚀天际线对比。无新增逐帧反射或天空渲染通道。
- 车身填充光比日落弱，主要由太阳与 HDR 塑造漆面。
