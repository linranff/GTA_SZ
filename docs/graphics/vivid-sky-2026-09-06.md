# 银河与月光薄云

夜空沿用 `src/city-night-sky.ts` 的现有天空球和材质，加入倾斜的银河、银蓝／淡紫外缘、暖色亮核、细尘带及更密的微小星点。银河与云使用连续方向噪声；薄云有冷色底光，靠近月亮更亮，并衰减背后的星光。保持线性 HDR 输出，由既有 ACES 管线显示。

白天沿用原始 HDR 云图，仅将可见天空的 `primaryColor` 从 `(0.92,0.92,0.92)` 微调为 `(0.94,1.02,1.10)`。日落、城市曝光及 PBR 环境光沿用原参数。没有新增资产、材质实例、渲染目标或绘制通道；夜空着色增加少量程序噪声计算。

验证脚本：`node scripts/check-vivid-sky.mjs`。当前生产构建通过，Chrome Metal 1920×1080 实际截图在 `output/playwright/vivid-sky/`，包括四向夜空、银河仰视、两向白天及昼夜切换。最终浏览器错误为 0；驾驶与银河仰视两个各 8.5 秒静止采样均约 60 FPS，P95 分别为 17.4 ms、17.0 ms，无超过 50 ms 的帧。这是当前机器的短时采样。

视觉复核：驾驶和西向天空可见完整倾斜银河，细星点集中于亮带；东向月亮周围有淡蓝薄云，南向也有稀薄云层；白云仍有明暗结构。原始测量在 `report.json`，构建与源码哈希在同目录 `review.json`。
