# 主角与咖啡厅角色步态修正

原步态使用大腿正弦摆动、小腿单向旋转，膝盖朝向和屈膝时机有误；动画步幅与真实移动速度不匹配，形成直腿摆动和滑行感。

本轮用 Blender 根据脚底轨迹反求大腿和小腿姿态，烘焙到原有骨架：落脚、支撑腿伸展、脚尖蹬地、屈膝回收、下一次落脚。膝盖朝角色前方，脚跟向后收。跑步带短暂腾空和较大的屈膝幅度；咖啡厅保留短步巡游。现有模型、服装、骨骼数量和招手动作不变。

`scripts/character_gait.py` 是共用的离线动作生成器；原始资产准备脚本已接入。`scripts/rebake_character_gaits.py` 可以直接重烘焙已清理的 Blender 角色，不必重新处理 Tripo 三视图。脚底接触取自实际鞋底采样，不在游戏中执行 IK；当前仍没有复杂地形的逐脚 IK 或布料模拟。

运行时从 manifest 的步幅和周期计算动画速度。主角的走路/跑步共享独立的步态时钟，混合动画时保持左右脚同相位。走路调整为 1.6 m/s，跑步 4.2 m/s；店员动画按实际巡游速度和角色显示比例缩放。停止时停止推进步态，渐变回待机。补上道路/人行道的实际表面高度，避免鞋底埋入比地形高的道路网格；咖啡厅沿用其真实地板高度。

验证结果：

- `tests/character-gaits.test.ts`：直接解码发布用 GLB，检查膝盖向前弯、支撑腿能伸展、动画周期无跳脚、支撑阶段的脚踝轨迹与标定移速吻合；三种模型通过。
- 步行、咖啡厅巡游及独立骨架回归共 8 项通过；资产权重/动画校验、TypeScript 与生产构建通过。
- `scripts/check-character-gaits.mjs`：实际游戏中采样主角走路 160 帧、跑步 163 帧，膝盖角度分别约 5–67°、12–116°；走跑动画相位检查通过。店内巡游角色测得约 15–62°，保留停步、招手和交谈逻辑。
- Blender 逐阶段侧面预览位于 `output/character-gaits/`；实际游戏录屏、截图和检查报告位于 `output/playwright/character-gaits/`。主角侧面鞋底与道路接触已复核；店内截图有家具遮挡，完整腿部形态另以 Blender 侧面图复核。

诊断量仅用于确认此次动作修复，不代表动画已达到动作捕捉或复杂地形适配的程度。
