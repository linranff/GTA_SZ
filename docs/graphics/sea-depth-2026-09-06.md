# 高空海面与草地条带修复 · 2026-09-06

用户截图中的大块水平闪烁来自地表与扩展海面争用深度，和细波纹采样产生的摩尔纹是两个问题。

## 原因与修复

原水域北界为 z=2604.890，陆地却延伸到 z=8999.975。远海扩展环沿水域包围盒铺设，误覆盖约 86.82 平方公里的内陆草地。陆地 y=0、海面 y=-0.25；无人机升高后若轨道距离较小，near 仍为 0.3、far 为 18000，深度精度不足使两层交替显现。

- `city-bay-water.ts` 改为沿原始 `terrain_*` 地形的世界包围盒向外铺海。最终边界为 `[-6788.1001, -14000.0005, 6788.1001, 8999.9752]`。保留四个四边形、八个三角形，沿用现有材质和反射贴图。对岸山体不参与扩大内环，以免海湾出现缺口。
- `city-observer-depth.ts` 按相机超过静态场景最高点的净空增加 near，上限 128。场景最高点在初始化时计算，包含建筑与山体，当前为 563.1895；不增加逐帧全城扫描。原有驾驶、座舱、步行和车辆观赏近裁剪设置保留。
- 前一轮水面波纹与反射过滤、俯瞰光柱功能保留。

匹配复现点：相机 `[-2664.203, 2079.428, -873.701]`，pitch=0.3，轨道距离=12。修复前 near=0.3，修复后 near=128，far 均为 18000。修复前复现了用户截图中的水平草地/水面切换；修复后的夜间横移序列及白天视角中，该大块条带消失。返回驾驶、车辆观赏和座舱的画面完整，near 分别为 0.75、0.15 和 0.04。
