# 晴昼路面、天空与远海衔接 · 2026-09-07

本轮在现有建筑浮雕、光比、山地与完整分辨率后处理改动上调整晴昼观感。目标是减轻沥青吸光感、积水白色贴片感和远海硬边；没有重建城市资产。

优化前源码快照和当时完整工作区补丁保存在 `output/playwright/daylight-coast/before/`。隔离重建的基线主包 SHA-256 与首次截图一致：`8252485623b3f6f9df97356cc5a59b76b8619eff19123a113ed6a0fa1cbbc501`。本轮源码指纹在 `output/playwright/daylight-coast/source-sha256.json`。

| 部分 | 晴昼调整 | 原因 |
| --- | --- | --- |
| 干沥青 | 纹理乘色改为 `[1.02,1.03,1.04]`；环境响应 `.55 → 1.0`；镜面强度 `.22 → .55`；扫描粗糙度中位约 `.92 → .80` | 恢复宽而柔和的天空反光，保留沥青颗粒 |
| 浅积水 | 环境响应 `1.35 → .85`；材质透明度 `1 → .74`；粗糙度 `.075 → .13`；镜面强度 `.85 → .65` | 露出下方路面，减小明暗跳变；布局、反射对象和覆盖率不变 |
| 天空与调色 | 关闭颗粒和色散；暗角权重 `1 → .25`；减弱分离色调，整体饱和度 `-5 → +3` | 保留蓝天与云层结构，减少灰脏感 |
| 远景 | 晴昼雾密度 `.00007 → .000045`；天空显示乘色 `[.76,.90,1.03]` | 远山层次更明确，太阳方向仍有合理空气透视 |
| 远海 | 1,800–14,000 游戏单位内按距离和视线掠射角渐融到同方向天空 | 消除远海的固定色条，避免巨大平面看起来像竖墙 |

晴昼曝光仍为 `1.08`，直射光 `3.0`、半球光 `.28`、场景环境强度 `.78`。HDR 太阳亮度肩部、太阳方向、IBL 与原素材一致。路面与积水通过 `setMode()` 恢复日落和夜间的原参数，贴图尚未加载时切换模式也会记住最新选择。

远海读取现有可见天空立方体，沿用其旋转、线性/伽马标记、强度和显示乘色。它没有新增立方体、反射目标、光源或顶点；远水像素最多多一次立方体取样。水面实际高度仍为 `-0.25`，反射平面同步。低视角的海平线本应近似直线，本轮没有制作显眼的球面弧线。晴昼少了两个全屏通道，保留街道 4× MSAA、无人机 FXAA 和原有半分辨率接触阴影。

可查看固定机位的[原画面](../../output/playwright/daylight-coast/before/01-day-road.png)和[新画面](../../output/playwright/daylight-coast/after/01-day-road.png)。同一块干路面取样区域 `(520,840)–(660,930)` 的显示亮度约从 42.6 提高到 56.7（0–255），朝阳天空区域约为 210.3 → 210.4。数值用于说明路面改善来自局部响应，不代表全场景或物理亮度。

具名视觉复核：

- `01-day-road`、`02-day-car-rear`、`03-day-car-front`：干湿路面的明暗差缩小，车漆高光和颗粒细节仍可辨认，天空更清楚。
- `06-bay-aerial`、`07-west-coast`：远海硬边减弱，对岸山地不再被同一条高对比蓝带包住。
- `07b-coast-eye-height`、`07c-coast-25m`：实际相机高度约 1.92 m、24.92 m；岸线和建筑遮挡正确，没有水面抬升盖过建筑。
- `09-sunset-city`、`10-night-city`、`11-return-day-road`：完成日落、夜间、晴昼往返，材质参数及抗锯齿恢复正常。远海天空融合目前只用于晴昼。

`npm test`：126 通过。新增检查覆盖模式切换后处理顺序、抗锯齿与通道去重，以及复用天空、不增加纹理、不移动近岸水位、无兼容天空时关闭融合。`npm run build` 通过。Chrome Metal 的 13 个实际画面没有页面、HTTP 或 GPU 着色器错误，输出分辨率为 1920×1080、DPR 1。报告在 `output/playwright/daylight-coast/after/report.json`。
