# 晴天高光与山地起伏（2026-09-06）

本次在当前分支增量修改，不回退城市细节，也不重建基础城市资产。

## 晴天

晴天 HDR 原始太阳像素的线性亮度约为 368349。此前它直接参与环境漫反射和粗糙反射预过滤，叠加定向太阳后容易出现大片白色高光。`city-daylight-environment.ts` 在立方体解码后、SH 与粗糙度预过滤前，对亮度超过 8 的太阳高光应用连续肩部曲线，渐近上限为 32；普通蓝天和云层亮度保持原值。强太阳光略偏暖，天空补光保持冷色，并降低晴天半球补光、车身补光和雾密度。

源 HDR 未修改，天空与 PBR 使用同一个处理后的环境贴图。没有新增每帧渲染通道或额外环境纹理。夕阳和夜间保留原有参数。

复核：`scripts/check-daylight-balance.mjs` 的同机位前后对比位于 `output/playwright/daylight-balance/{before,after}/`。已查看车头、车尾、城区和海面；车漆太阳高光收敛，蓝色漆面更容易辨认。云层依然会形成较宽的浅色反射。改后城区静止 6 秒采样约 60.01 FPS、p95 19.7 ms，无浏览器错误。这是该场景的短样本，不代表所有设备或连续驾驶性能。

## 山地

`scripts/prepare_city_mountains.py` 复用项目缓存的 Copernicus GLO-30 E113/E114 两块 DSM，源字节哈希和输入资产哈希写入 `public/city/mountain-relief/*manifest.json`。原生分辨率为 30 米；近景网格以 20 米实地间距插值，不提高实测精度。高程经过表面尖峰抑制、平滑、城市基准面扣除和山脚过渡，是游戏地形改编，不能当作裸地测量结果。

- 北侧远景网格间距 60 米实地，127944 个三角形、32 块，最高约 315 游戏米；游戏垂直缩放为 0.60。
- 城区绿地网格增加 53510 个三角形、45 块。笔架山、安托山、燕晗山等绿地补出坡面，也在安全的绿地内部加入低幅草坪起伏。
- 两组共 181454 个三角形、77 块，高度数据共 2484244 字节；复用已有草地材质，不增加纹理或反射渲染通道。
- 保留现有莲花山高度场、机动车道和建筑底座。山中步道按新高程抬升，树木、路灯与地面采样保持一致。
- 北侧仍是地形背景，未扩大可驾驶城市范围，未宣称重建范围外的建筑或道路。

运行生成器需要项目 Python 环境中的 NumPy、Rasterio、Shapely、SciPy：

```sh
.venv/bin/python scripts/prepare_city_mountains.py
.venv/bin/python scripts/prepare_city_mountains.py --near
```

`tests/city-mountains.test.ts` 验证采样与渲染三角形一致、两组高程有限且非负、原莲花山区域无增量，以及机动车道路中心和左右边缘没有抬升。原草坪小起伏已重采样并合入这一个高度网格；原材质与覆盖纹理保留，不再加载和叠加旧缓坡网格。因此相较于之前实际净增 126481 个三角形、31 个地形分块，高程/网格下载净增约 0.82 MB。山体依靠坡面法线与环境光形成明暗，接收建筑和树木阴影；不加入现有低分辨率大范围阴影图的自投影，以免山坡出现阴影条纹，也不增加阴影绘制。

具名视觉复核由 `scripts/check-mountain-relief.mjs` 生成。
