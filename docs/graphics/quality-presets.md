# 低、中、高画质配置

实现日期：2026-09-12。入口位于游戏右上角「画质 · 中」，默认中档。切换即时应用并保存到当前浏览器；存储不可用时仍能在本次会话切换。菜单支持方向键、Enter、Esc 与外部点击关闭，地图/城市生活等覆盖界面以及隐藏 HUD 时不显示。

`?quality=low|medium|high` 可固定验收档位，优先于已保存选择；URL 覆盖本身不写入存储。测试保存行为时使用不带该参数的网址。

## 当前参数

| 项目 | 低 | 中 | 高 |
| --- | --- | --- | --- |
| 内部渲染像素上限（16:9 时） | 1600×900 | 1920×1080 | 1920×1080 |
| 阴影贴图边长 | 1024 | 2048 | 2048 |
| 街面屏幕空间环境遮蔽 | 关闭 | 4 样本 | 8 样本 |
| 道路、水面镜面反射贴图边长 | 256 | 384 | 512 |
| 移动时镜面反射更新间隔 | 3 帧 | 2 帧 | 1 帧 |
| 静止时道路／水面更新间隔 | 5／6 帧 | 3／4 帧 | 2／3 帧 |
| 车辆局部反射探针 | 关闭，保留环境反射 | 开启 | 开启 |
| 街面抗锯齿 | FXAA | 最高 2× MSAA | 最高 4× MSAA |
| 泛光处理比例 | 1/4 | 1/2 | 1/2 |
| 颗粒、色差效果 | 关闭 | 关闭 | 黄昏／夜间开启 |
| 街面近景树木／远景树木上限 | 18／160 | 36／200 | 48／220 |
| 高空树木上限 | 600 | 900 | 1200 |
| 街面树木半径（游戏单位） | 360 | 440 | 440 |
| 高空树木半径 | 1000 | 1200 | 1200 |
| 部分近景配景实例预算比例 | 50% | 75% | 100% |

渲染像素数按视口比例缩放，DPR 另有 1.5 上限；低档在 1080p 窗口内上采样显示，不能称为原生 1080p。抗锯齿尊重 GPU 的最大采样数。高空视角所有档位沿用 FXAA、关闭屏幕空间环境遮蔽、阴影每 12 帧更新；返回街面恢复对应档位。切换阴影尺寸时显式恢复更新间隔，避免重建贴图后退回每帧刷新。

所有档位保留同一套天空、日照、雾色、海面颜色和基本反射观感。调整画质不改变车辆、道路布局、碰撞、导航或建筑身份；树木只改变可见实例预算。低档没有引入“反射区域外换成另一种海色”的处理。

## 验收与限制

本轮 `npm test` 的 222 项测试通过，覆盖画质参数优先级、损坏或禁用存储、Retina / 4K / 超宽屏像素预算；`npm run build` 通过。切档中的 AA、颗粒、色差与泛光参数采用一次后处理管线重建，减少重复编译和材质失效。

2026-09-12 集成人员在当前 Mac 的 Chrome、1920×1080 视口、`http://127.0.0.1:4176/` 对当前生产构建完成了以下功能复核：

- 三档菜单的选中状态与切换提示正确，低档 canvas 实读为 1600×900；高档选择后刷新页面仍保持高档。
- 查看了黄昏高/中档、夜间低档、晴天中档实际画面，未出现黑屏或明显渲染缺失；这不代表逐地点的美术验收通过。
- 方向键与 Enter 能切换选项；Esc 收起后，G 能立即进入/退出无人机观景；观景模式中也可切档。
- Esc 收起后 M 能打开城市地图，地图覆盖时画质入口隐藏；最终保存回中档。
- 浏览器记录中未发现 error。检查后关闭测试页面并恢复视口。

CDP 的个别读取/点击曾超时，切档结果随后从原生无障碍状态及截图确认；没有将这些超时推算为游戏帧率，也没有取得中/高档 canvas 的刷新后实读尺寸。该记录只验证切换与界面，不等于目标电脑性能通过。RTX 3060 实机尚未测试，CPU、显存及桌面/移动型号仍需记录。

本轮是手动画质预设，不是自动识别硬件，也不是自动帧率调节。目前三个档位仍下载同样的主要城市模型与贴图，草地系统的整体预算、建筑网格密度、交通/行人模拟并未全部分档。低档主要降低绘制与后处理开销，不能保证解决 CPU 瓶颈、加载体积或显存不足。

## 后续硬件验收

固定浏览器、1920×1080 视口与实际渲染分辨率，分别在 M1 Max 与 RTX 3060 上运行同一条路线。其他游戏页面关闭，记录 GPU/CPU/显存/浏览器版本。先预热，再录街面驾驶、春笋近景、雨夜反射、高空俯瞰各 60 秒，报告平均帧率、帧时间 P95/P99、最长卡顿与场景。

60 fps 对应约 16.67 ms 帧预算。必须同时看帧时间分布和画面，不以短时平均值宣布稳定达标。高档先作为 RTX 3060 的待验证目标，中档作为默认；测试结果决定是否调整参数，不能直接按显卡名称承诺帧率。

后续可分别派给执行者：普通建筑原型的 LOD 候选、可重复的截图/性能采样工具、纹理资源统计。建筑 LOD、实例化、资源按需加载和模拟更新频率等架构接入由一个集成人员负责；只有接入后实际少绘制、少加载，才能计入性能收益。

实现入口：`src/city-graphics-quality.ts`（预设与保存）、`src/city-graphics-panel.ts`（菜单）、`src/city-world.ts`（渲染接入）、`src/city-landscape.ts`（树木与配景预算）。
