# 夜间草地、山丘与积水变化

夜间草地与莲花山增加保留纹理颜色的自发光补亮，同时提高直射受光、环境反射和局部灯光容量。入口为 `src/city-landscape-lighting.ts`，接入地面草材质、近景草叶与导入草丛；夜间新加载的材质也应用当前模式。

| 夜间参数 | 原值 | 当前值 |
| --- | ---: | ---: |
| 地表／草叶自发光补亮 | 0 | 0.42／0.32 × 当前表面颜色 |
| 直射漫反射增益 | 1 | 1.55 |
| 地表环境反射强度 | 0.75 | 1.45 |
| 地表镜面强度 | 0.32 | 0.68 |
| 同时接收灯光上限 | 3 | 6 |

补亮随表面法线略微衰减，保持坡面层次。夜间粗糙度减小 0.12，下限为 0.72；白天和黄昏恢复原有材质参数。没有新增光源、纹理或渲染通道，但更多灯光计算有 GPU 成本。整体曝光和建筑 Bloom 参数沿用上一轮设置。

积水由原有一种岸线增加到五种：原有曲折岸线、泪滴、双盆窄腰、弯曲凹岸、错位缺口。道路种子稳定选择形状、左右方向、长度、纵横偏移和小角度旋转，刷新不会重新跳位。继续合并成两个网格、共用道路镜面。

布局版本更新为 2。生成器先四舍五入最终紧凑数据，再调用运行时 TypeScript 函数生成 12／6／4 段轮廓；Python 验证三种 LOD 的完整外缘并集，避免两套岸线公式不一致。最终 62,661 处积水，完整轮廓覆盖可用道路并集的 30.11%，另两种 LOD 为 28.30%／27.10%；路面外面积为 0，重叠面积仅为浮点误差。开场 440 米内显示 418 处、14,148 个三角形、2 次绘制。正式布局与内嵌缺失资源回退均已更新。

验证：74 项项目测试通过，TypeScript／Vite 构建通过，真实城市 Shapely 边界检查及 Babylon NullEngine 几何、预算、资源恢复检查通过。NullEngine 另行确认昼夜恢复、晚注册、重复注册和材质释放。临时的完整轮廓中间文件已删除。

浏览器复核入口：`node scripts/check-night-landscape.mjs URL OUTPUT_DIRECTORY`。截图及报告在 `output/playwright/night-landscape/{before,after}/`；使用实际本地构建、Chrome Metal、1920×1080，通过普通键盘和鼠标前往相同视角。草地近景通过 UI 定位，前后存在约 0.13 米偏差；莲花山使用同一固定观景位。

具名视觉结论：开场路侧草地暗部可辨、路灯下更亮；深圳湾草地近景保留细纹理和暗色草根；莲花山坡面与公园灯池之间的亮度过渡清楚；开场俯视道路的积水起止与岸线不再整齐重复。白天和再次切回夜间均正常，控制台及资源错误为 0。
