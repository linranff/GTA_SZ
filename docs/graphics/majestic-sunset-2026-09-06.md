# 火烧云与靛蓝天空

傍晚的薄层摄影云改为密集的橙红火烧云全景，暖侧覆盖大半圈方位，向背光侧的暗靛蓝过渡。云带延伸到头顶，保留蓝色云隙、深色云底和金橙亮边。夜晚和晴昼继续使用各自的环境。

原图由 Codex 图像生成工具参考用户提供的火烧云图片生成，原生尺寸为 1774×887。`scripts/build_sunset_environment.py` 使用 Blender 5.2 对齐地平线，处理横向接缝和极点，定义暖冷半球并烘焙线性环境贴图。4096×2048 的双线性烘焙用于避免 Babylon 最近邻全景采样造成的方格；它不会增加原图细节。完整源图、来源与哈希在 `data/art-direction/` 和 `data/materials/cinematic-environment.json`。

同一份环境辐射用于天空、车漆和玻璃。PBR 保留高于 1 的亮部能量，天空显示单独压缩高光，避免为压住天空而再次把车和玻璃变成哑光。这是生成图的艺术化辐射重建，并非实测 HDR 摄影。海面和积水沿用原有的场景反射。

复核入口：`node scripts/check-majestic-sunset.mjs`，需先构建并在 5173 运行预览。图像在 `output/playwright/majestic-sunset/`。

2026-09-06 当前资产已完成驾驶起点、无人机四个方向、头顶、夜晚及晴昼共 8 个画面的复核：橙红侧与暗靛蓝侧有明确区分，顶部云层连续，重采样消除了初版可见的方格，海湾和车窗反射采用新天空。页面和控制台错误为 0；72 项测试与生产构建通过。没有运行新的帧率基准，也不以历史性能数据宣称本资产锁定 60 FPS。

仍有边界：这是静态天空全景；近看云层的原生细节与真实高分辨率摄影、可运动的体积云仍有差距。当前改动没有新增逐帧渲染通道。
