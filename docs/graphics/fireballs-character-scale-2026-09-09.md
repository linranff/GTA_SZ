# 连续火球与咖啡厅角色比例修正

旧爆炸将大量径向光斑同时叠在撞击点，导致中心过曝成白色圆斑。本次换成九个错时出现的有噪声细节的体积火球，0–1.21 秒分批引爆，先横向扩张再向上翻卷。火焰内部有明暗与烟尘遮挡，随时间冷却成浓烟；另有四轮火星喷射、余烬及 24 片翻滚碎片。镜头有短促震动和轻微后移，爆炸声补充两次后续低频冲击。仍在撞击后 3 秒返回普通无人机。

体积、材质、粒子池均在起飞前准备并复用，碰撞时不新增全城动态灯光。新模块 `src/city-flight-explosion.ts`；飞行入口仍是 `src/city-flight.ts`。

角色没有父节点误缩放，旧模型确实约 1.69 / 1.67 个游戏单位。但模型眼线偏低，咖啡厅吧台约 1.265、椅面约 0.575，玩家眼高为 1.68，造成明显的俯视与比例落差。现按实际网格包围盒归一化为知夏 1.96、望舒 1.93、小岚 1.95 的**场景显示高度**，不是现实身高。视觉增高约 14%–17%，横向仅较等比放大收窄 3%；鞋底保持原锚点，未改位置、对话、玩家视点、家具或原 GLB。

验证：

- 飞行、爆炸生命周期、咖啡厅相关 20 项 Node 测试通过；连续重复爆炸不会累计资源，退出后火球、粒子、碎片全部清理。
- TypeScript / Vite 构建通过。
- 当前实际游戏 11 项飞行检查通过，无浏览器错误；九团火球、四轮喷射和碎片可见，撞击后约 3025 ms 恢复无人机。记录：`output/playwright/city-flight/report.json`。
- 当前爆炸静帧：`output/playwright/city-flight/03-building-impact.png`。静帧暂停用于观察，恢复时间来自单独的正常实时流程。
- 角色固定镜头前后图和实测比例：`output/playwright/cafe-character-scale/`，`comparison.json` 记录三位角色高度与落地检查。已复核女仆、JK 和吧台角色，未观察到浮空或桌椅穿插。
