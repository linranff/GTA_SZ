# 深城纪当前实现基线：用于对标分析

审计日期：2026-09-12。只读代码、当前 GLB 与现有截图/诊断报告；本次没有运行新浏览器测试，没有改动游戏。下述判断是我们的基线，不能据此推断对标作品使用了什么渲染技术。

## 结论

主要差距不宜概括成“没有高级光影”或“电脑不够好”。我们已经拥有 HDR 环境、PBR、环境反射、平面反射、车辆局部反射、接触阴影、局部灯光、雨天、车辆音效/BGM 和多种玩法。当前最明显的问题是大地图的资产精度分布不均：塔楼轮廓已有识别度，但驾驶视角最常看的首层、路缘、绿化、街道设施和人物之间存在大面积空白，材质和模型风格也不统一。继续只加全局后处理，很难补足这些缺口。

## 当前画面直接暴露的缺口

复核现有 `output/playwright/roadside-trees/02-bamboo-driving.png`：可辨认春笋及城市道路，但近景大片绿地空隙、底层楼面缺少门窗/营业空间/遮阳/标识层次，重复立面一直延伸到地面。光照阴暗部分占驾驶画面较大面积，细节不足又使这些区域更空。应先处理街面组成与局部材质，不宜只把曝光继续抬高。

复核 `output/playwright/roadside-trees/04-tall-roadside-tree.png`：树种颜色已有区别，但树干分叉简化，树冠仍能看出叶片卡片堆叠与重复形。最近树木改动是混合分布与实例缩放（`src/city-roadside-planting.ts:180`），**没有新建高树种模型**（`src/city-landscape.ts:103` 明确说明），因此不能当作树木资产品质已升级。

这两张图呈现的问题更接近“景观/街道资产的中尺度信息不足”：例如树池—灌木—树干—树冠的层次、底商—台阶—入口—遮棚的层次、路缘—排水—磨损—停车空间的层次。它们比继续堆细碎噪声、光晕或更密窗格更优先。

## 性能证据与建议预算

最近 `output/playwright/roadside-trees/report.json` 和 `roadside-trees-4173/report.json` 的五个场景都约30 fps、p95约33.4 ms，报告明确失败。各场景几乎完全一致的30Hz提示测试环境/呈现节奏需要复查；同时 GPU 指标约10–23 ms，部分场景真实超过16.67 ms，不能把所有问题都归为限帧，也不能说稳定60fps。

这些样本总 draw calls约504–1044，render submit约7.3–13.1 ms，约2,100 loaded meshes。树木局部 draws 约24，单看树数量不能解释全部负担。全城楼体、道路、重复反射/阴影/接触阴影 pass应分别归因。

用户最新指示将主目标调整为RTX3060的1080p/60fps，M1 Max保留轻量档；3060的桌面/笔记本型号、显存和CPU尚待确认，目前没有3060实测。建议先做一条约1–1.5公里的“春笋—人才公园/滨海”完成度路线；保留全城可游览，但把新增高精资产集中在可验收路线。暂定预算需要在目标设备固定浏览器/1080p/前台独占下实测校准：

- 帧时间目标16.67 ms；为流式载入/交通保留余量，稳定段 GPU 目标不超过12–13 ms，CPU更新与提交目标不超过8–10 ms。两者并行，不能简单相加。
- 对新增树模型先定3–5种明确轮廓，每种有2–3个造型和近/中/远 LOD；保持近树数上限而改善单棵形体。更远的整排冠层用合并批次或 impostor，避免把高模半径直接扩大。
- 先减少道路/基础城市与多 pass的重绘成本，再把节省预算投入首层、道具、树影和车辆周围；每个系统分别记录主视图/阴影/反射 draws 和 GPU 时间。
- 普通画质保持现有有限实时探针；展示画质可提高车漆探针或局部阴影，须明确是画质档而非宣称所有 Mac 都能同档60fps。
- 每次验收用固定日间、黄昏、夜景、雨景四个镜头和连续120秒驾驶；同时审空白率、资产接缝/穿插、动态反射稳定、材质一致、p95/p99帧时间及加载峰值。不能只挑宣传镜头。

## 推荐开发顺序

1. 固定对标截图、相机高度/FOV、光照时段与性能测法，先消除30Hz样本歧义，形成当前基线。
2. 在一条完成度路线建立统一材质标尺和街道模块：路缘、人行道、首层立面、入口、店招、树池、设施、停车空间；从玩家眼高验收。
3. 做真正有树形差异的高大榕树/阔叶/棕榈资产及 LOD，统一人物、车辆和树木的细节级别与色调。
4. 用新增街面形体完善接触阴影、环境遮蔽、局部间接光近似与反射内容；广场和建筑首层可研究烘焙光照/环境遮蔽，而不是全城加实时灯。
5. 把既有步行、驾驶、交通、工作和音效串成一段稳定、自然的游玩体验，再把这套质量扩展到下一街区。能力数量已经很多，下一轮更需要让这些能力在同一条街上成立。
