# 观景输入与清晰度修正 · 2026-09-05

适用于 G 无人机、地图地点观景与 V 看车。驾驶时仍使用 WASD。

**本文件保留上一轮输入验收记录。用户后续明确修正为：普通拖动（三指系统拖动同样）旋转，只有 Shift + 拖动平移。当前规则见《雨后红霞与城市层次-2026-09-05.md》。下表是已被取代的旧映射，不作为当前操作说明。**

| 输入 | 观景行为 |
|---|---|
| WASD | 沿当前视角的前后左右移动 |
| ↑ ↓ ← → | 相机在原位转头、抬头和低头 |
| Q / E | 降低 / 升高 |
| 按住鼠标左键或触控板单击并拖动 | 抓取画面式平移；松开即停止 |
| 右键拖动 / Alt + 左键拖动 | 围绕当前目标环绕 |
| Shift | 键盘移动加速；按住拖移加速 |
| 滚轮 | 远近 |
| G / F | 返回驾驶 |

鼠标没有按下时，移动不会推动观景镜头。pointercancel、失去capture和窗口失焦均清理拖拽状态。

用户希望三指仍用于旋转；代码在浏览器确实提供三指TouchEvent时保留该分支。macOS的“三指拖移”是系统指针拖拽功能，若浏览器只收到普通鼠标拖动，网页没有指数量可用，不能可靠与物理按压拖动分开。该系统手势未在用户实际触控板上独立验证，不宣称已自动识别；方向键、右键或Alt拖动提供确定的转向入口。系统功能见[Apple说明](https://support.apple.com/en-gb/102341)，网页可得到的指针数据见[W3C Pointer Events](https://www.w3.org/TR/pointerevents/)。上述事件不可区分性是按事件模型作出的条件判断，不是Apple对本游戏的兼容承诺。

## 已验证

`output/playwright/visual-upgrade/second-integrated/report.json`：左键按住平移、松开后零漂移、悬停鼠标移动零漂移，方向键相机坐标保持不变且朝向改变，右键环绕通过。17项CPU行为测试通过；该轮GPU脚本/图形警告均为0。

Retina模拟场景CSS 1115×874、DPR2，实际游戏渲染1626×1274，总像素不超过原1080p预算。截图2230×1748是输出尺寸，不能把它误报成实际3D渲染尺寸。当前策略按DPR、1.5倍上限和1920×1080总像素预算选最小倍率。

路牌保留1024×256，主字由77提升到112像素，中英文分组和箭头重排；各向异性过滤提高到8。没有通过移除mipmap换取静态截图锐度。

建筑主题与夜光经历三轮 GPU 迭代，第二轮控制通过不代表同轮黑白碎窗外观通过。第三轮 `output/playwright/visual-upgrade/third-integrated/report.json` 为 pass，脚本及图形错误、警告均为 0。根任务于 2026-09-05 复核开场同机位黄昏和夜间的 HUD／无 HUD 截图：v2 已消除上一版明显的黑白棋盘与白色碎点；楼体呈现连贯主色，夜间窗户有局部暖色柔光。远处夜窗仍偏密，属于后续艺术调整；不据此宣称全城视觉已完成。

主题插件采用楼栋级稳定参数，修正透视插值引发的随机值跳变，保留带 mipmap 的连续纹理梯度采样。夜窗使用发光材质配合现有 bloom，不代表每扇窗新增实体光源或物理体积散射。最终 v2 候选 SHA-256：`8cba1502fcb368d50fc71fd705498b6a10e16cfab87e7bcc6352e7e882c068ac`。

第三轮仅用于日夜视觉复核，不是帧率验收。当前生产包的持续性能测试由“规划 Blender 城市场景实现”任务继续执行，不能沿用之前版本的 60 FPS 数据。
