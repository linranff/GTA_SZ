# ShenChengJi v0.2 — City lights & GT sport kit

A playable Shenzhen browser-city update, with English documentation and complete Simplified Chinese and Japanese editions.

## Highlights

- Blue daytime skies, a photographic sunset, a Milky Way night sky and softly illuminated thin clouds.
- Original building facades and materials retained in aerial views, with local detail and lighting centered on the area being viewed.
- More distinct dark floors and lit windows, brighter nighttime landscape lighting, and varied roadside puddles.
- A rear wing, four metal exhaust outlets and cold-white HDR headlights for the player GT.
- Driving, walking, drone exploration, map navigation, autopilot and repeatable city-life contracts in the current build.

## Run this version

Install Node.js 24 and Git LFS, then clone the `v0.2` tag, run `git lfs pull`, `npm ci` and `npm run dev`. For a production preview, run `npm run build` and `npm run preview`.

The GitHub-generated source archives may contain LFS pointers rather than complete game assets. Use Git with LFS to obtain the playable assets. The release tag is **v0.2**; the package and asset-manifest version is **0.2.0**.

## Verification

90 tests and the production build passed. The delivered asset inventory was refreshed and checked against all 3,429 listed files. Current game screenshots and short performance measurements are recorded in [the graphics review](https://github.com/linranff/ShenChengJi/blob/v0.2/docs/graphics/city-quality-sport-2026-09-06.md); they do not guarantee a stable frame rate across all hardware or the whole city.

The game remains a prototype and its UI is primarily Simplified Chinese. The language editions in this release are documentation, not in-game language packs.
