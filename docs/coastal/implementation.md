# 深圳湾驾驶、倒影与公共照明

2026-09-06，Babylon.js 8 / Blender 增量。对应本轮关于沿海海景、倒影延迟、跨水道路、公园灯光和驾驶手感的修改。

## 原因与变更

1. 倒影原先驾驶时每2/3帧、高空每6帧更新。相机改变后继续投影旧图像，会产生错位。相机移动/转向或拖动期间，路面和海面倒影逐帧更新；停止动作后保留220ms，再恢复静止时低频更新。移动的是同一帧的真实反射相机，无延迟插值。现有512反射分辨率与剔除保留。
2. 原来的水面缺少受光水波、浅水与岸线分层，远处缺少对岸地势。海面改用受太阳/月光影响的PBR，四组世界坐标风波，随距离过滤高频法线，小幅扰动平面倒影采样。近岸距离图只控制色彩和弱泡沫，不把水面整体涂白。岸边增加竖直堤岸/散石，对岸采用GLO-30远景网格。
3. GLB经meshopt压缩后，节点保留量化缩放和平移。海面统一高度通过world/local矩阵转换，不能直接把游戏米写到local Y；回归测试覆盖该问题。所有可见水面与水面镜像平面使用同一world Y=-0.25。
4. 原来的两盏路灯池在重新选灯位时清零，导致开车时明灭。现在按灯身份保持槽位、远离后淡出；静态世界照度场独立提供每盏附近路灯的地面漫反射。两盏实时灯继续贡献近处高光。路边方向牌改为固定、受控的文字亮度，不再随灯池切换突然变亮/变暗。照度场是1024²纹理，覆盖2048游戏米，中心每256米更新，边缘软衰减。材质在tonemapping前接收照度，并保留贴图与表面法线，不是屏幕上的发光贴片，也不是每盏灯各开一个实时阴影。
5. 220个高杆公园灯位覆盖44个公园/活动空间。杆体在Blender建模，实例位置贴合当前地形；几何先烘焙压缩节点变换，再施加游戏位置。红树林/湿地不布置该高灯层。
6. 固定OSM水体与道路相交得到164条跨水片段。桥面抬高2.8游戏米，并用70米平顺过渡接回现有道路；同步驾驶高度、道路几何、灯杆、桥边护栏和支撑。桥梁高度/结构是游戏重建。后海二桥、后海大桥纳入，其他立交和隧道并未完整恢复。
7. 手动转向增益低速0.76、高速逐渐降至0.54，保留自动驾驶原来校准过的车辆物理。小地图以缓存2D地图作透视平面，随车速轻微倾斜，无人机模式接近俯视；不增加第二个3D场景渲染。

## 构建与来源

入口脚本：`fetch_coastal_dsm.py`（固定哈希下载），`prepare_coastal_infrastructure.py`（OSM交叉、灯位、近岸遮罩、远岸DSM），`build_coastal_infrastructure.py`（增量Blender），`optimize_city.mjs`（压缩）。所有路径以仓库根目录运行。具体命令见README。

`public/city/coastal/infrastructure.json`保留实际道路ID和灯位。`far-shore.json`保留DSM下载来源。原始DSM不提交；运行资产和构建代码由Git/LFS管理。原始30m DSM不是30m建筑模型，70游戏米远岸抽样只表现地势。

官方滨海绿道参考：[深圳湾绿道介绍](https://cgj.sz.gov.cn/xsmh/szlh/jpld/content/post_2053209.html)，用于海湾、对岸山峦、步道与栏杆之间的层次安排。[派生地形署名](../../public/licenses/coastal-terrain.md)。

## 验证入口

- `tests/coastal-infrastructure.test.ts`：跨水道路高度/平顺坡道、手动转向响应、压缩GLB水面world高度。
- `scripts/check-coastal-upgrade.mjs`：用户操作进入驾驶、无人机快速拖动、后海二桥瞬移、流花山夜景、小地图；检查脚本/HTTP/WebGL错误、镜像刷新帧、world水面高度。截图需要人工视觉复核。
- `scripts/check-city-rain-drive.mjs`：实际自动驾驶路线和帧时间。截图短测不能证明全城稳定60fps；每次性能结论必须指向本次构建。

草坡/草坪由独立的草地更新提供，其所属文件、审计和性能结果另行记录。

## 材质切换兼容性

最终组合的启动检查曾偶发两条 `Active draw buffers with missing fragment shader outputs`，同步GPU诊断未复现该时序问题，因此不能宣称已经取得失败program的证据。源码审阅发现车辆玻璃同时使用depth-only/MRT颜色变体；当前仅对此材质禁用 `allowShaderHotSwapping`，禁止新变体编译时复用前一pass的旧effect，保留透明度和深度预通道。修改后无诊断的完整日夜/移动短测未再发生该错误，最终连续驾驶仍纳入同类错误检查。诊断工具现在保留colorMask，诊断模式不能用作性能结论。

## 最终结果

当前源码 TypeScript/Vite 构建通过，58项单元测试通过。无诊断的日夜/桥梁/相机/小地图短测10张截图无JS、HTTP、GL错误；快速拖动30/30采样同帧倒影，小地图倾斜由22.3°随车速变化至27.1°。具名复核中桥面在水上，公园高灯与街道照明分离，海面有风波与建筑灯光倒影；日间对岸已降低亮雾染色。

最终连续自动驾驶出生点→腾讯→深圳湾，两次到达，实际440.07秒、6172.3游戏米；1080p Chrome Metal下平均59.9615fps，P95 16.7ms、P99 16.8ms，超过50ms的帧1个。JS/HTTP/GL错误为0。末尾草地六张纹理全部ready，草簇189实例/1draw/6615三角形，0失败与待加载瓦片。完整可复现摘要及本次源码/运行包SHA见 [verification.json](verification.json)。这只描述本次路线与设备，不代表全城、所有浏览器都锁60fps。
