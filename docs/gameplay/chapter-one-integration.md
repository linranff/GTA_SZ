# 第一章：雨停以后

2026-09-06。本轮把城市观景驾驶推进为可重复游玩的生活原型。仍是 Babylon.js 浏览器游戏，Blender 制作资产；不是完整 GTA 规模产品。

## 如何游玩

1. `J` 打开生活手账。日结打工者、年轻职场人、城市工人都可立即选择；三个基础合约都在出生点附近的海湾驿站接活。
2. 接单后按世界标记与小地图导航前往，或者点任务卡“自动前往”。停车按 `E` 取餐、接人或交接。
3. 配送考核准时，接送考核急刹/急转带来的舒适度，巡检需要逐站保持停车完成作业条。接送的主要行程必须在车内完成；到站可以下车交谈。
4. 每单结算现金、品质奖金和身份经验；同一身份完成两单升到 2 级并开放进阶工作。所有合约可重复。
5. 第一单和第三单分别触发人物消息。可以付费请客，也可以选择不花钱的相处方式。关系影响熟人奖金；阿琳有友谊/进一步约会的分支起点。
6. 保温箱、乘坐缓冲套件、巡检工具会改变具体工作规则。¥1,800 房间基金是一项存钱进阶目标，目前没有房间室内。

`F` 停稳后下车，进入第一人称步行；WASD 行走、方向键/按住拖动看四周、Shift 快走，回到车旁 5 米内 F 上车。车辆留在原位，步行不增加车里程。禁止穿越水域、楼体、陡峭高度差及新驿站主体；人物全身动画尚未实现。

`L` 依次切换日落、月夜、雨后晴日。`G` 保留无人机，鼠标/触摸板拖动环绕、Shift 拖动平移；`M` 保留道路贴合的快速跳转和地点观察镜头。三座新驿站可在地图中搜索、跳转或近景观察。

旧三段顺路故事移到手账“沿途故事”，可取消进行中的旧单再切换职业。旧钱包一次迁移到同一份 v2 存档，防止重复领取。合约在地图/无人机/手账中暂停计时；R 回到道路或调试瞬移使当前合约不能结算。刷新保留钱、关系、升级和完成次数，进行中的合约需重接。

## 新增资产与协作分工

- 玩法 agent：纯状态机、3 个身份、6 个合同、4 个升级、6 段双选项关系对话、10 个经济与状态测试。
- 资产 agent：原创 Blender 生活驿站，23,222 三角面、27 材料子网格、1.95 MB。实体门窗框、棚架、商店陈列、中文菜单、取餐架、花箱、长椅和电动车。布置在 3 个经过土地/道路/建筑/水域校验的地块；脚印 14.2 × 10.2 游戏米。
- 光照 agent：4K CC0 蓝天积云 HDR、匹配的太阳方向/玻璃车漆反射/曝光/远雾。保持夜景与日落。
- 主 agent：共享世界与 UI 集成、第一人称步行、世界任务标记、地图驿站入口、主菜单与收据、资产阴影与反射、功能和游戏内视觉验证。
- 交叉审阅已修复空消息状态读取、旧任务无法退出、步行巡检被误算停车、全程步行送客、高空换光后阴影范围滞后的问题。

## 与目标参考图的真实距离

不能用一个可靠百分比衡量，也不能把一張参考图当作已运行游戏的证据。目前能看到相同的城市驾驶构图、海湾、水面、车漆反射和多种时段，但大多数街段仍没有参考图里持续出现的精细底商、立面凹凸、遮阳构件、入口、人行道家具与自然绿化密度。地理骨架已有，近景资产密度和美术一致性尚有明显差距。

本轮只把生活驿站这一类近景资产提高到可检查细节的水准。它不是整条深圳湾街区已经达到同一质量的证明；不能称为 3A 城市。对角度固定的小段街景，可以继续精细制作并逼近参考图；全城、全天候、任意视角都保持该水准，需要大量资产与场景美术工作。

玩法从“开车看景”发展为“接活—操作表现—收入—升级—关系”，仍缺可持续改变城市的随机事件、成体系的人物动画/对话演出、交通规则与事故反馈、室内据点、更多车辆及其功能差异、长篇剧情和多小时内容。当前最值得继续做深的是深圳湾 1–2 公里的连续生活街区和三位人物的任务链，而非继续铺大面积重复楼体。

## 后续开发次序

1. 把首个生活驿站周围连接成有真实底商、公交站、单车停靠、人行横道和通往海边步道的连续街段，精修近景材质和美术层次。
2. 将任务结果做成可见世界变化：修灯后照明恢复、取餐后货架改变、人物登车/下车、下班时段聚集，以及小范围交通事件。
3. 发展日结搭子、职场边界和城市工人班组故事；约会需要可走的地点和共同活动，不能只堆菜单文字。
4. 建成可使用的住处、休息/换班和车辆/工具成长；之后再做大规模性能压缩与 Steam 封装评估。

本轮没有运行长时间 FPS 基准，也不沿用上一版本的 FPS 数字证明新版本性能。测试聚焦实际完成一份配送、消息与升级、存档、上下车、地图和光照。
