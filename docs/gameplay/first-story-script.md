# 《最后一单》旁白与字幕稿

2026-09-12。可选过场/字幕用，与 `CITY_STORY_CONTENT` 对白一致。本文件是文稿，**未配音、无音频文件、未进游戏**。运行时按合同：到站停稳、下车、短对白可跳过；不要把本稿当成已经挂好的 VO。

预估朗读加驾驶见 `story-bible.md`，不等于实测。旁白里标了「待布景」的细节，不要当成画面已经有。

## 用法

- 旁白：每站最多一句现场，外加必要的待布景标注。不评价玩家。
- 字幕：说话人 + 正文，对应内容数据的 `lines`。选择按钮用内容数据的 `label`，不要另写一套。
- 跳过：整段可一次跳过；跳过后仍要到目标点停稳下车再交互。
- 滨海交货时阿辉人在海湾生活驿站，用电话/对讲即可，不必出现第二具阿辉模型。
- 导航只指向海湾生活驿站、科苑下班驿站门前/窗口、公园城市养护站、滨海路边交接点。
