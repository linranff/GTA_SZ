# 《最后一单》人物与口吻

2026-09-12。叙事交付，供玩法按 `src/city-story-contract.ts` 读取 `CITY_STORY_CONTENT`。人物与事件均为虚构。本文件不写运行时代码，也不把预估时长当作实测。

## 工作名与边界

- 工作名：最后一单。任务 ID：`bay-last-delivery`。奖励固定 ¥180，两条分支相同，不按品质浮动。
- 主线是都市配送与人情冲突：收工前的最后一袋热饭、科苑驿站核销、是否为公共设施绕路。
- 不写犯罪组织、不写真实企业作反派、不把枪械或战斗写入本任务。武器试验场是另一份独立工作包，与本线人物无剧情关系。
- 不接职业线的约会/请客分支，不改钱包实现，不新增大名或新地点坐标。地点只用已有 `hub` / `office` / `park` / `bay`。`workshop` 本任务不出现；结尾由阿辉口头提到「下次走维修站」。

## 人物关系

来源是现有 `src/city-career.ts` 的三个身份与关系人，外加本任务里的玩家。玩家没有另外起名。

| 人物 | 既有身份 | 本任务里做什么 | 和玩家的关系 |

| 阿琳 | 年轻职场人；工作群、准点离开、看海 | 帮滨海那单点了晚饭，要在科苑下班驿站见面核销；中午顺手签了寄到本站的卡箍 | 职场线熟人。她在窗口把事情交完就回公司，不坐你的车 |
| 老陈 | 城市工人；雨后巡检、路灯、排水 | 人在公园城市养护站等卡箍；今晚还要换管，过道会积水 | 巡检线熟人。绕路时只在养护站收零件，不留玩家作业 |
| 你 | 默认可玩日结配送 | 领袋、对码、选路、交货、回驿站 | 本任务只开口交代动作，不替自己下判断 |

人物之间不另建组织：

- 阿辉与阿琳：只通过这张订单见面核销，不当面聊天。
- 阿辉与老陈：驿站和对讲里认识；班组零件有时落到驿站。
- 阿琳与老陈：不是同事。卡箍寄到科苑下班驿站，她中午代签，一直没人送出去。
- 本任务不改变职业线里「请热饭 / 调勿扰 / 认真约会」等已有选择的存档含义。若运行时要写关系值，由玩法另定；文案不承诺加减。

## 统一口吻

短、具体、可执行。每人每站 1–3 句。不写鸡汤，不写旁白替玩家评价「你做对了」或「这一程值得」。

- **阿辉**：口语，工钱和热饭放在前。收工就说收工，晚点就说温了，不上升到日子过得值不值。对照既有：「今天的饭还热着，别赶到危险，稳稳送过去。」「一百八打你账上。」
- **阿琳**：先把事情说完，再提工作群催她回去。不撒娇，不把核销说成命运安排。对照既有：「今天开了六个会。」本单：「工作群催我回去，我得先走。」
- **老陈**：只讲今晚要干的活和让人走。谢可以有一声。对照既有：「雨刚停，灯和排水都得看一眼。」「走，回驿站喝口热的。」
- **你**：答动作，不总结意义。本任务不写玩家对白；选择按钮即玩家态度。

禁用：温暖、值得、原来生活还可以、你感到、这一单证明了。需要环境信息时，写玩家找得到的位置：海湾生活驿站、科苑下班驿站门前/窗口、公园城市养护站、滨海路边交接点。未建细节只在脚本里标待布景。

## 事件怎么接上职业线

本任务是一条一次性试玩，不是替换 `hot-meal` / `quiet-ten-minutes` / `after-rain-round`。物件和地点都从那三条基础合约里来：

- 保温袋、海湾生活驿站、滨海路边交接点 ← 阿辉「热饭趁热送」的取餐与路边送达。
- 科苑下班驿站、工作群、下班临界 ← 阿琳「把十分钟还给自己 / 今天准点离开」。核销发生在驿站窗口，不是未建的写字楼门厅。
- 公园城市养护站、卡箍、夜路积水 ← 老陈「雨后巡检」。排水作业是他收工后要做的事，零件本该走维修站；玩家不去未建排水口。

冲突不是「好人/坏人」，是同一晚三件事抢同一辆车：阿辉要结班、阿琳被群催回去、老陈要换管。直接去滨海，热饭赶上换班，卡箍留在科苑驿站到明早。绕公园养护站，当晚能换管，交接点收到的是温的。工钱都是 180。

## 分支图

所有节点从 `hub-pickup` 可达，且都能进到带 `terminal: true` 的结尾。选择至少改一个后续地点（是否经过 `park`）和一段结尾对白。step / choice ID 与结构不变。

```
hub-pickup (collect, hub)
  → office-meet (talk, office)
        ├ go-bay-direct → bay-direct (deliver, bay) → hub-end-direct (talk, hub, 终止)
        └ detour-park   → office-spare (collect, office)
                              → park-help (deliver, park)
                              → bay-after-park (deliver, bay)
                              → hub-end-detour (talk, hub, 终止)
```

同一地点的后一节点都有当场动机，不是为了凑时长把人按在原地：

| 地点 | 第一次 | 第二次为何还在这儿 |
| --- | --- | --- |
| hub | 阿辉值守，交货袋 | 结算。直送：他已拿到换班前截图，并转告老陈明早来科苑驿站取卡箍。绕路：他已听到饭温了的回执，和对讲里老陈那一声 |
| office | 阿琳核销并抛出选择 | 仅绕路。卡箍在她包里，工作群催她回公司；取走就开车，不等她 |
| bay | 路边交货 | 两条分支各一站，对白不同：烫手签收 / 不烫也签了 |
| park | 只出现在绕路 | 老陈在养护站收零件，不当场巡检，不要求等待作业条 |

## 预估时长不是实测

目标试玩 10–15 分钟，靠开车路段，不靠站内倒计时。下列数字按现有生活点间距和「停稳、下车、读 1–3 句」估算，**不是**本机或目标机实测，总控跑完再记偏差。

| 路径 | 路段 | 预估 |
| --- | --- | --- |
| 直送 | 海湾生活驿站→科苑下班驿站→滨海交接点→海湾生活驿站 | 约 9–14 分钟 |
| 绕路 | 同上，另加窗口取物和公园城市养护站一站 | 约 12–17 分钟 |

绕路可能略超 15 分钟，算选择代价。若实测过短，由总控决定是否加驾驶距离，不在对话里加等待。若过长，先砍停顿和重复提示，不砍分支地点差。
