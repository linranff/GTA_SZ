# 视觉资产与无人机更新 · 2026-09-05

当前生产预览 http://127.0.0.1:4173/ 已安装本轮资产。此记录对应 cinematic/HUD 下一轮接入之前的构建。

- 建筑：8种手工窗墙图集、由原OSM用途辅助分类、每栋稳定相位及逐窗亮灯；UV2 metadata保留几何、UV0、颜色和索引。修复了GPU预处理吞分号造成楼面缺失的问题。两张新图约6.67 MiB显存，另有既存备用建筑纹理约3.33 MiB；不能只计新图开销。材质变体本身增加0 draw call。
- 车辆：Khronos CarConcept（CC BY 4.0）派生的双门靛蓝GT，非小米SU7。Blender源可编辑，78,825三角、26 primitive、2,143,520字节；四轮轴心和滚转半径按实物模型导出，前刹车只随转向，左后刹车盘已对齐。CPU轴心、转动、排重、白灯/尾灯实际发光强度通过。
- 地面：原创沥青/草坪纹理、榕树/羽叶棕榈/开花乔木、草束/花灌木/观赏草、近景井盖和排水格栅。7,933个树位、64,010个地被候选经过整路网/陆地/水体/建筑排除；远近LOD和可见实例上限控制渲染负担，未把所有植物加入反射。
- 镜头：G、地图观景与V看车共用CityObserver。WASD/方向键沿镜头平移，Q/E降升，Shift加速，拖动环绕、滚轮远近，G/F返回驾驶；观景移动保持车辆位置和行驶里程不变。高空暂停频繁阴影刷新并关闭近景AO，回到低空自动恢复。
- 腾讯屋顶字样已核对GPU正面可读、朝向正确、无矩形底和遮挡；位置仍是来源照片估计，不宣称测绘精度。

## 剩余画面差距

具名地标玻璃的色差仍偏块状，腾讯连廊材质较单薄；远景草坪还有重复感，近景冠层与行人仍可细化。普通窗墙图集不是每栋实景立面复刻，现有阳台/装饰线和新窗格在部分建筑尺度不完全一致。反射环境、车窗高光和路面整体光比由下一轮cinematic统一校准，不能据本轮结构通过宣称最终美术达标。

交通车辆仍是单独的轻量原型，未把玩家高精度模型复制到全路网。全量源重建改为隔离候选目录，源流程已列入新资产但尚未端到端跑通；当前交付不会被默认重建静默覆盖。
