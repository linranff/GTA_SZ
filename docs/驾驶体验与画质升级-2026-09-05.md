# 驾驶体验与画质升级

本轮整合车辆与驾驶舱、地图与自动导航、免费环境素材、音效，以及另一个任务完成的 HDR／夜景修正。试玩入口为 http://127.0.0.1:4173/ 。

## 已实现的交互

| 用户需求 | 当前行为 |
| --- | --- |
| 车内镜头穿模、看不到仪表 | `C` 切换到实际驾驶位置；车体遮挡按视角处理。新增方向盘与薄圆角仪表，显示真实速度、挡位、里程和灯光状态；方向盘跟随转向。 |
| 更精致的大地图和更多地名 | `M` 打开地图，支持搜索、分类、缩放、拖动和路线预览。现有地标与新增 OSM 片区、公园、地点、地铁站合并为 305 个地点；道路名随缩放显示。 |
| 自动导航到目的地 | 地图选择地点，点击“自动驾驶”。车辆通过现有道路与驾驶物理行驶，处理转弯、前车与必要的低速调整，抵达后停车。WASD／方向键／空格或导航栏按钮可接管。 |
| 主角车辆与牌照 | 保留已授权 CarConcept 的外形和细节，增加真实驾驶舱、清漆、漆面微纹理、透明车窗及轮胎／轮毂材质；车尾牌照为“深城纪”。 |
| 尾灯缺少照射 | 尾灯照亮邻近路面、路缘及积水接收面；刹车时增强。新增一盏受范围约束的灯，没有新增阴影贴图。 |
| 更好的树和其他素材 | 加入 CC0 阔叶树、棕榈与木／金属长椅，保留真实贴图和近远景版本。经过道路、楼体、水面及绿地边界检查的 6,261 个树位采用新素材，其余保留原资产。 |
| 没有车辆音效和 BGM | 首次点击或按键后启用电驱、胎噪、风噪、刹车与喇叭；原创合成 BGM《海湾晚风》。`H` 鸣笛，`Esc` 中分别调节音乐／音效及静音。 |
| HDR、自然光与反射 | 黄昏天空高光压缩、统一环境反射，收窄泛光；夜间改为中性环境，清除无来源的橙色楼脚光斑，调整亮窗，增加稀疏星空。 |

`V` 近距离看车，`L` 切换日落／夜景，`G` 无人机。无人机普通拖动环绕，`Shift + 拖动` 平移。

## 素材与实现边界

- 阔叶树：[Poly Haven Island Tree 03](https://polyhaven.com/a/island_tree_03)，Rico Cilliers / Rob Tuytel，CC0。源资产经过离线 Blender 简化与叶簇重建，游戏近景 10,590 三角面、远景 1,829 三角面；不会把原始高面模型直接放进浏览器。
- 棕榈：[Yughues Palm tree v2](https://opengameart.org/content/palm-tree-v2)，CC0，每株 1,032 三角面。
- 长椅：[Poly Haven Modular Street Seating](https://polyhaven.com/a/modular_street_seating)，Stuart Attenborrow，CC0。重组、降模后 6,150 三角面，最多同时显示 12 张，位置来自已有 OSM 数据。
- HDR：[Poly Haven Belfast Sunset](https://polyhaven.com/a/belfast_sunset)，CC0。运行时使用预过滤环境贴图。

完整署名在 `public/licenses/open-city-assets.md`。下载清单、官方校验值、衍生模型和树位检查保存在 `artifacts/driving-experience-candidate/`。BGM 与音效由项目代码合成，没有使用外部歌曲或录音。

驾驶舱新增 1,634 三角面、7 次绘制，仪表贴图最多每秒更新 10 次；树木实例化并限制近景预算，长椅复用材质与实例。车体基础网格没有重新设计，城市普通楼体与部分街道细节仍属于现有原型，与最初写实参考图仍有差距。

自动驾驶使用项目现有道路图。目的地需有可达道路；导航不等同于完整交通法规模拟。按最新开发需求，地图中常驻“瞬移到附近道路”和“俯瞰此处”按钮；普通选点先预览，点击对应按钮执行瞬移或俯瞰。

## 验证记录

- 41 项项目测试通过；自动驾驶扩展检查 20 项通过，包含从出生位置到全部 13 个地标的到达与停车。
- 真实 Chrome Metal 中，经地图启动、手动接管、重新启动，完整行驶到腾讯滨海大厦并停车；约 245 秒行驶段平均 59.99 FPS，P95 16.7 ms，无超过 50 ms 的 rAF 帧间隔。该长路线记录来自最后一次仪表造型与材质调整之前，见 `output/playwright/driving-experience/report.json`。
- 最终驾驶舱修复中发现并纠正了 Babylon 自定义面的绕序问题。CPU 射线检测不能代替 GPU 可见性，最终结果以本轮实机截图为准。
- 资产清单只读检查通过：240 个运行时文件，231,044,791 字节。全部许可证和资源哈希随工程保留。

驾驶舱最终三图在 `output/playwright/cockpit-delivery/`：静止、行驶、夜间均显示完整仪表，没有屏面黑片；速度 000→053、挡位 P→D 与 HUD 一致。地图焦点修复后的 `M → Esc → Esc`、暂停返回及无人机退出后实际驾驶均通过。

## 持续性能结果与后续集成

2026-09-05 的 300 秒检查使用 `index-DHeVVqvj.js`、M1 Max、Chrome 152 Metal、真实 1920×1080。实驶 3,984 个游戏坐标单位，平均 **54.00 FPS**、rAF P95 **33.3 ms**、27 个超过 50 ms 的帧间隔；测试键盘控制器发生一次 R 恢复。持续性能门槛**未通过**，不能用早前的 245 秒短路线结果替代当前结论。79 个实际 HTTP 资源均已绑定 SHA256，零脚本、加载和着色器错误。

完整记录为 `output/playwright/driving-experience-delivery-perf/`，包括 `report.json`、`diagnostics.json`、`motion.json`、`frame-times.csv` 和 `timing.svg`。此后用户在协作任务中要求恢复更明显的建筑／车漆反射、常驻地图瞬移和俯瞰、提高导航速度及修正高空裁剪；相应源码进入后续统一集成。地图按钮已落盘并通过类型检查，新的整包视觉与性能结论须由该次构建重新验证。
