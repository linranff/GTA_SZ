# 春笋 / 平安参考图试点观察

2026-09-12。图在本机 `artifacts/landmark-references/`（gitignore），用 catalog 里的 `commonsFiles` 可重下。全部 CC BY-SA 4.0，只作视觉参考，不当贴图。

## 春笋

阴天湖面和晴空高位两张能看形体：连续笋形、密竖挺、底扩顶针、银白金属。暮色远景只能核剪影，不能取色。同框的 mixc 方塔和春茧网架是邻居。还缺街面入口。

## 平安

远景是浅色缓收分 + 斜向高光肋 + 短冠细桅。街面仰视玻璃变蓝灰，亮边一直顶到冠部。底座前有裙楼商业，广告牌不是塔。还缺配准过的入口和夜景依据。

## 第二波（京基 / 地王 / 深交所 / 春茧）

本机观察稿在 `artifacts/landmark-references/<id>/observations.md`。

- **京基100**：高位是深色圆角缓收分、曲顶细桅。另外两张是 KK MALL（粉柱、波纹银板、三角雨棚），不是塔。缺街面塔身和与地王的同框。
- **地王**：青绿双筒、双圆冠双桅。同框时它较矮、偏青；京基更高、更深、单筒圆头。
- **深交所**：方塔坐在抬高悬挑裙楼上，底下斜撑/格构，石墙店名已对上。坐标仍 unknown。
- **春茧**：花生形白网架，右团大椭圆开孔。绿色整面是临时广告。不要捏成单一体块。

## 建模含义

春笋更鼓、更针；平安更直、有截顶。京基是深色单筒曲顶，地王是青绿双筒双桅，两栋必须能并立辨认。深交所先做悬浮平台和架空，春茧先做连续屋盖和开孔。腾讯候选接入前不新建共享模块。下一波建议：`guomao`、`seg`、补一张京基街面塔身。
