# 重点场所：公开证据与首轮几何修正

研究日期：2026-09-05。机器可读清单为 `data/landmarks/priority-places.json`；可重建参数为 `data/landmarks/priority-models.json`。地点按本轮纠正后的“七街公馆 / 哈尔滨大厦”记录。仅保留公共建筑信息。

当前最明显的问题不在多边形数量，而在楼高、分段体量和实体辨识：哈尔滨大厦在现有城市数据中按未知类型估成现实约39m，财富广场A/B分别约18m/30m；万象天地的几栋塔楼忽略了已有 `building:part` 退台。首轮模型先修正这些结构差异。高度尚无测绘证据的楼体仍显式标记估计，不称为测量级重建。

## 七街公馆 / 哈尔滨大厦

高德公开POI将哈尔滨大厦定位于北环大道7045号七街公馆，深圳房地产信息网也列出七街公馆的备案名为哈尔滨大厦。它与科技园内的“哈尔滨工业大学大厦”是不同对象。[高德POI](https://ditu.amap.com/place/B02F38J15R)、[楼盘记录](https://bol.szhome.com/house/2532.htm)

模型位置直接取本地WGS84轮廓质心 `[114.02751878, 22.56047975]`，不采用商业地图坐标推算。OSM只画出一个连续H形轮廓，不能据“A/B座”名称擅自拆出两幢独立楼。公开实勘相册和房源有33层线索；当前总高102m是建模估计，尚缺层高及楼顶绝对高度。[乐有家实景与楼层线索](https://shenzhen.leyoujia.com/xq/detail/1091.html)

已在Chrome目视检查两张照片：远景中的银灰楼体有密集竖横框线；门口可见蓝灰窗、灰白围护、凹入阳台、玻璃雨篷。右边棕色楼体是相邻建筑，未套用到七街公馆。照片路径为2018年，拍摄日期本身未核实。[整体远景](https://fang-community.leyoujia.com//pic/hsl/2018-07/17/35346e99-628d-4242-8ac9-a64f6adf9e5d.jpg?imageView2/1/w/720/h/405)、[入口与立面](https://fang-community.leyoujia.com//pic/hsl/2018-07/17/b6c701f6-debf-42df-a05d-1ef107f87a6d.jpg)

当前模型实现H形主体、下部深色商业区、银灰框线、蓝灰窗格和浅阳台横杆。窗格间距是外观近似，不能视为楼层户型。入口雨篷缺准确侧向配准，本轮没有添加虚构门口位置。

## 万象天地

设计方直接说明了mall+街区组织。华阳项目页的69.46hm²、380万㎡是华润城整体尺度，不能填成万象天地商场单体规模。华润2025年局部改造招标另给整个商业办公综合项目79.8万㎡、商业约21.8万㎡口径，并列出T6低层、高街、影院等改造范围；2017开业照片不能直接代表今天的店铺。[设计方项目页](https://www.capol.cn/projectdetail.aspx?id=100000068055563)、[设计方对街区形式的说明](https://www.capol.cn/newsdetail.aspx?id=100000189216119)、[华润改造招标](https://www.crpsz.com/zbxx/006001/006001001/20250603/942f12a2-a6a8-404e-a6e0-ebf657060afe.html)

## 后续Agent的固定输入与验收

1. 从清单选择一个地点，先核对别名、地址、坐标系和目标边界；街区与单楼任务分别列组件。
2. 只裁取目标周边数据。轮廓用WGS84；高德等坐标保留其原坐标系，经转换核对后才可融合。[高德坐标转换文档](https://lbs.amap.com/api/webservice/guide/api/convert)
3. 按来源把轮廓、总高、分层、顶冠、阳台和入口拆成事实/估计/未知。收集带时间的四向照片和至少一个尺度基准；缺尺度不能宣称摄影测量精度。
4. 建模者只用经审查的参数；参考图不直接打包成游戏纹理。外观在公共资料范围内重建，不加入室内细节。
5. 验收地理位置、轮廓、朝向、街道视角比例、顶冠剪影、主材质和两级LOD。来源不足的部分保留估计标签。

当前调用：`scripts/landmarks/priority.py` 暴露 `build(b, lm, spec, scale=.6)`，`spec`为参数文件的单个`models`元素；`lm=None`时自动以项目原点投影。返回`baseBuildingIds`，集成时仅排除这些旧楼体，不能用整个研究框删除背景建筑。不要同时输出“整栋最大高度挤出”和相应分段体量。

已完成参数与模块检查：12组件闭合有效轮廓、投影往返、来源ID、六个旧楼体替换ID隔离、坐标有限值和builder frame恢复通过。实际GLB构建与场景截图由主构建任务验证。

## 财富 A 连续弧面解释（2026-09-05）

[整体实景](https://fang-community.leyoujia.com//community/album/2019-06/10/10/0bf01030-5f46-4f65-90b7-2864d64e6156.jpg)显示连续弧形蓝玻璃、银白水平带和宽白色竖向实体墙。A 座原始 `footprintWGS84` / `footprintLocalMeters` 保留不变；渲染和碰撞可使用新增 `renderFootprintWGS84` / `renderFootprintLocalMeters`。分别对外长边索引 `[9,10,0,1,2,3]` 和内长边 `[4,5,6,7,8]` 做最小二乘圆拟合，采样弧长不大于 2.5m，并线性加入两端残差以固定原端点；`3→4` 与 `8→9` 两条直封口保持不变。B 座仍为原矩形。圆心、半径、起始角、转角、端点修正和采样数已存入参数文件，可复现。

外弧源点径向拟合残差最大 0.947m，内弧 0.491m；渲染闭环与原折线的最大 Hausdorff 偏离 2.489m，面积变化 1.30%。这些是相对 OSM 的解释改动量，不代表与现实的绝对误差。两端加宽至 4.5m 的白色竖墙为照片引导估计，端部位置与宽度均未测量；入口悬挑、圆柱仍待照片配准。状态保持 `photo_interpretation_estimated`，不能称测量级高精度。
