交给执行者：

你只负责上表指定的一个对象和阶段。先读AGENTS.md、spec、证据摘要、B API与一个样板模块。按真实米制数据和项目统一缩放创建候选；不要重新研究已冻结项。若关键资料自相矛盾，列冲突并提交判断；不暗改规格，也不为完成任务编造背面、店招或高度。

先让主体足印、楼数、高宽比、退台、凹口、连廊和屋冠成立，再做材质/窗格。构件使用共享材质与合并/实例化；不每窗创建独立mesh。建立LOD候选时同时交真实几何统计和远景图；运行时还未接入就标candidate，不声称已提高帧率。

只改上表允许文件。现有`priority.py`和总GLB属于集成者，不能动。工具没有明确独立输出能力则停止构建并交模块，不能尝试给共享构建器附加未支持的参数。对路径含短横线的对象模块，使用现有已验证加载适配，不自以为普通Python import可直接支持。

每阶段保存相同相机与光照的图，逐项对照辨识特征：写具体差异与对应结构；不使用总分替代结论。误差容忍按spec预先规定，没有配准的照片不用逐像素比较。只允许一版加两轮针对性修复，同类问题持续就交最小差异包。

交付源码、真实候选GLB、输入/源码/输出哈希、灰模/材质视角图、实读面数/材质/文件统计、实际构建命令、差异说明、未知项与integration-notes。没有执行的步骤标未执行；不能因文件存在就把collision/browser/performance填pass。由集成人员接入实际游戏后才补这些验收。

最后交一屏摘要。需要Pro处理时只递交当前目标、3张最相关图/来源、具体冲突、最多两个方案与推荐；不要附整个历史对话要求重新研究。
