## 制作方法

独立入口 `trailer.html` / `src/trailer-capture.ts` 加载同一套 `DrivingWorld` 与项目资产。每推进 1/60 秒模拟时间才编码一帧，使用 WebCodecs 输出 H.264，然后通过 FFmpeg 剪辑与混音。未用静态勘景图片充当动态视频，也未通过插帧或重复帧补齐帧率。

相机使用 `src/trailer-shots.ts` 中的导演轨迹；车辆镜头沿现有滨海大道连续道路作排演，独立更新车轮、车身、车灯、车流与行人。排演轨迹用于摄影，不作为自动驾驶功能验收。录制期间使用固定时钟更新水纹与草地风动，预加载所拍区域的立面，按输出帧刷新倒影和阴影。拍摄画质为 4× MSAA、FXAA、1024 倒影、4096 阴影与纹理各向异性过滤；曝光、雾和灯带按昼夜分别调整。

音乐在现有原创曲《海湾晚风》的旋律与和声上重新合成编曲，72 BPM、36 小节，片长正好两分钟。车辆音效按录制的速度与镜头距离生成；升空段渐弱。最终音频采用静态增益调整，保留动态范围，无旁白。

成片为 SDR / Rec.709，H.264 High、YUV 4:2:0、AAC 320 kbps 立体声、fast start。最终视频平均码率约 17.8 Mbps。拍摄过程按固定时间推进，**影片的 60 fps 不是这台 Mac 的实时游戏性能结论**。

## 重拍入口

1. `npx vite build --config vite.trailer.config.ts`，然后在 `output/trailer/site/` 重建 `city -> ../../../public/city` 符号链接。
2. `npx vite preview --config vite.trailer.config.ts --host 127.0.0.1 --port 4187 --strictPort`。
3. `node scripts/record-trailer.mjs`；只补拍指定镜头可用 `--shots=10,11`，短样片可用 `--sample`。
4. `.venv/bin/python scripts/render-trailer-audio.py`；重新分析 `mix.wav` 的响度后运行 `.venv/bin/python scripts/assemble-trailer.py`。

导演入口与正式游戏页面分开。共享游戏代码只增加了草地风动的可选固定时间来源；普通游戏未设置该字段时仍按原来的时钟运行。首轮样片中间文件已经清理，正式镜头、配乐分轨与母版保留以供后续剪辑。
