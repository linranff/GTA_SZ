# 深城纪 · 天际之上

第二支影片为 120 秒、1920×1080、60 fps 的全新城市航拍。用户要求保留 HUD，因此全程显示品牌、片区、无人机界面和城市小地图，地图位置与朝向跟随导演相机。提供配乐版与无音轨素材版，两者均保留 HUD。

镜头起止使用各 10% 的速度缓入缓出，中段保持连续移动；长距离飞越增加少量弧形运动。机位全部在真实三维场景中移动，没有用截图缩放代替飞行。极远试拍会暴露当前地图的矩形范围，因此最终视野集中在有建模的城市内部。

HUD 为现有无人机界面的 Canvas 导出，直接复用游戏 `drawCinematicMinimap`，地图由真实城市道路与建筑数据绘制。小地图方向来自相机视线，焦点来自相机目标；不显示虚假的车速。提示文字随画面保留，鼠标不入镜。

影片在独立的 `trailer.html?reel=aerial` 入口拍摄，内部以 2560×1440 渲染后缩采样至 1920×1080，使用 4× MSAA、FXAA、4096 阴影和 1024 反射。逐帧推进固定 1/60 秒，不依赖本机实时画面是否达到 60 fps。录制时关闭交通以外的玩家输入，车辆与水面保留引擎状态更新。游戏主入口与第一支影片输出保持原样。

音乐《天际之上》为本片原创合成配乐：120 BPM、半拍听感，使用弦乐和铜管音色、钟声、低音、鼓点和空气声。镜头切点均落在整小节边界，无旁白、外部歌曲或录音采样。混音经过两遍响度处理，最终以 AAC 320 kbps / 48 kHz 立体声封装。
