# 七街与腾讯低位招牌：承载面补证

复核日期：2026-09-05。本轮只读已有模型、OSM 轮廓及公开照片，没有修改共享 JSON、模型或贴图，没有启动浏览器/GPU。

结论：**七街入口可以做中等置信度的估计放置，但应同时补上有照片依据的雨篷承载体；腾讯低位蓝色双语牌暂不安装。** 下面的坐标均是对现有游戏模型的计算或照片解释，不能称为实测。

## 七街公館入口：可按西侧中部凹口估计

[搜狐焦点七街公馆项目页](https://www.focus.cn/xf/sz-51785/)明确列出“小区入口:西面”。这是较早楼盘资料的公开陈述，不是竣工图或当前现场核验；同页仍包含规划中地铁等旧文案，因此置信度不升级为测绘事实。原[入口实景](https://fang-community.leyoujia.com//pic/hsl/2018-07/17/b6c701f6-debf-42df-a05d-1ef107f87a6d.jpg)显示招牌在两侧较凸出楼翼之间的低层凹口，安装于外挑雨篷上缘，左侧同一楼体有乐有家门店。这个凹口拓扑与地图 H 形楼体的西侧中部相符。

本地 `data/processed/xiangmihu/roads.geojson` 的[景田北七街 way/245962638](https://www.openstreetmap.org/way/245962638)在楼西侧；北环大道辅路在楼北侧，景田北八街在南侧。[哈尔滨大厦 way/364716846](https://www.openstreetmap.org/way/364716846)的西凹口面只对应当前 `priority-models.json` 原始 ring 的 `8→9`。此判断组合了“西面入口”的文字、入口实景凹口及道路/轮廓关系，**没有用北环大道门牌推断门朝北或朝南**。

补看了项目页链接的[总平面原图](https://t.focus-img.cn/xf/zxc/01f503b33a18d8032e67de80062f25bc.jpg)与[施工平面原图](https://t.focus-img.cn/xf/zxc/3c95bf26c2ad4a1d3a96d03dc863f67e.jpg)：总平面只有448×424且褪色，入口标注无法可靠识读；施工图只能核对北环在北、青海大厦在东的邻接关系。没有把施工出入口或不可读箭头作为最终公共入口证明。尚缺一张带道路和整个门口的可定位实景或清晰竣工首层总平面。

可以交给当前模型的估计方案如下。原始闭环最后一个重复点不计，索引按 JSON 原顺序，不按运行时反转后的 ring。

| 参数 | 值 | 证据类型 |
| --- | --- | --- |
| 西侧凹口墙边 | ring[8]=`[-10.0361,-7.5531]`，ring[9]=`[-12.5148,4.3025]`，相对楼质心，物理米 | 来自既有 OSM 轮廓的计算 |
| 墙面长度与中点 | 12.1119m；`[-11.27545,-1.62530]` | 同上 |
| 外法线 | East/North=`[-0.978835,-0.204649]`；正北顺时针 **258.191°** | 同上；此值不是实景相机测量 |
| 文字从左到右的水平轴 | East/North=`[0.204649,-0.978835]`，即大致从北向南 | 面朝西的字牌几何约定，避免镜像 |
| 雨篷前缘外挑 | 从凹口墙向外法线方向 **3m** 起稿，允许2–5m范围 | 照片解释估计；真实伸出量未测量 |
| 字牌中心 | 相对模型质心 East/North/Up=`[-14.21196,-2.23925,6.4]`m | 位置与高度估计；沿墙中点约±2m，垂直约±1.5m |
| 中心 WGS84 | `[114.02738060,22.56045963]` | 从上述估计点投影回算，只是定位表达，不增加精度 |
| 游戏 East/North/Up | **`[146.90674,1633.70791,3.84]`** | 原点 `[114.025,22.536]`，102850/111320 m/°，统一0.60倍；Up相对模型地基 |
| 字牌总体尺寸 | 宽8.5m、高1.8m起稿；范围宽7–10m、高1.3–2.2m | 照片比例艺术估计；双行文字保持原图层级 |

字牌应为中文“七街公館”在上、较小全大写 `SEVENTH AVENUE RESIDENCE` 在下，金黄实体字，参见上一份招牌清单。当前 `scripts/landmarks/priority.py::_qijie` 只有主体、裙层和立面细节，没有该雨篷。**可放置的前提是补出简化雨篷并把牌落在其前缘上方；不要在该坐标单独悬空放一张字牌，也不要把它贴在凹口上方住宅窗面。** 若本轮只允许给既有网格加贴花，则仍保留安装 pending，因为照片中的承载体尚不存在。西侧判断为中等置信度；沿面偏移、外挑、尺寸、高度为低到中等置信度估计。

## 腾讯低位 Tencent 腾讯：暂不放置

[腾讯官方蓝字近景](https://www.tencent.com/wp-content/uploads/2022/12/25a8bceda571cbb43a6775a035930efd.jpeg)可确认蓝色 `Tencent 腾讯` 在横向百叶/铜棕色低层体上、玻璃大堂上方；照片右边还有玻璃楼面。但[官方媒体页](https://www.tencent.com/newsroom/media-resources/)只给通用 Tencent headquarters 标题，并混有另一座旧总部照片，因此不能仅以标题或铜色判定某一个模型面。

本轮新增的[第一财经公开外景](https://img.yicaiglobal.com/src/image/2022/01/18850271028838400.jpg)（[原新闻页，2022-01-10](https://www.yicaiglobal.com/news/tencent-is-said-to-buy-china-no-1-gaming-phonemaker-black-shark-for-usd4079-million)）同时显示双塔、底部百叶连接体、蓝色双语字牌和广场金属立字；[财新公开入口图](https://img.caixin.com/2021-03-23/1616496765492553.jpg)（[原新闻页，2021-03-23](https://www.caixinglobal.com/2021-03-23/tencent-music-and-warner-music-launch-joint-venture-and-extend-licensing-deals-101679211.html)）补充了百叶体下的退入玻璃入口。它们加强了“滨海大厦低位入口有这套蓝字”的实体关联，**尚不能把官方近景中的具体字组可靠对应到东西两侧的连接面或某塔包覆段**；不能假定各图一定是同一面、同一套牌。

已对照[NBBJ 项目页](https://www.nbbj.com/work/tencent-global-headquarters)的建成实景，包括[广角双塔 N62](https://data.openasset.com/32707b49/affbbb40550c57b02910bc0766d5febc/100796_00_Tencent_N62_tif/100796_00_Tencent_N62_screenview.jpg)及[邵峰高位外景](https://images.prismic.io/nbbj/0090ab1e-f8ef-4bd7-b396-a2cec471c61a_100796_00_Tencent_ShaoFeng_N12_large.jpg?auto=compress,format)。这些视角支持双塔错位与连桥包覆的拓扑，但低位招牌区域被前景、画幅或距离限制，没提供“字牌—道路—哪一座塔”可同时读清的闭合对应。导视承建方公开案例图片本轮返回403，未把未能查看的图算作证据。

当前 `scripts/landmarks/tencent.py::_bridge` 的 `culture` 由中心连接矩形及两个不同转角的塔身包覆体组成，底14m、顶35m，平面与高度本身就有照片估计成分。该连接矩形两侧的几何计算值如下，**只是候选承载面定位，不是安装建议**：

| 当前模型候选面 | 外法线方位 | 游戏 East/North 的面中点 | 实景对应 |
| --- | --- | --- | --- |
| `culture` 连接矩形 `v=+22m` | 63.784° | `[-5826.08283,-675.38943]` | 未确认 |
| `culture` 连接矩形 `v=-22m` | 243.784° | `[-5849.76723,-687.05175]` | 未确认 |

本地[最低连接体 OSM way/601101655](https://www.openstreetmap.org/way/601101655)还保留了不对称外轮廓，它与当前概括矩形/套体不是严格相同的墙面。直接套上某个±v面可能落到错误包覆段；在对齐承载面之前，不提供文字中心高或字牌世界坐标，以免计算结果被误读为定位证据。

解锁所需信息很具体：一张能同时看到这套蓝字、两塔中的至少一个可识别端部以及相邻公共道路/广场边界的外景，或建设/运营方标明招牌立面的导视图；再把那个面对应到当前模型的包覆体/连接矩形。现有四张手工纹理中的蓝色腾讯双语图继续保留可用，安装状态维持 `pending_georeferenced_surface`。本轮不继续研究万象天地入口。

临时参考照片仅用于 CPU 目视比对，完成后清理；没有将照片、楼盘施工图或新闻图片加入游戏资产。主集成人员随后明确授权把本条西入口证据、法线、坐标及简化雨篷参数同步到 `landmark-signage.json` 的 `qijie-entry-bilingual`，现已标为 `renderReady=true`、`renderPlacementStatus=photo_interpretation_estimated`；其前提与估计边界保持如上。腾讯低位仍 pending。未修改 `public` 清单，等待集成重新生成。
