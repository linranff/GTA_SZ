## 交给贴图和安装模块的约定

文字使用手工 SVG 路径或明确字符的 alpha 贴图；英文大小写、中文传统字形和文字层级按证据保留。普通系统字体可帮助起稿，定制 Logo 与书法字的最终轮廓仍需人工对照。图生不能代写招牌文字。万象的大 X、小 the、下移 c 需要分元素布局，不能压成普通一行标签。

`textAssetReady` 只表示字可画；`renderReady` 才表示本轮已有可供核对的模型面方案。腾讯南塔顶的方位168°是立面外法线相对正北顺时针角；中心高0.96基于物理塔高248m。七街西入口的物理局部坐标和已缩放场景坐标在 JSON 中分开标注，所有物理尺寸进游戏只乘一次0.60。其他位置的未知朝向是 null，不允许默认为朝南。文字资产应保留透明底，不能用整块发亮矩形掩盖字形；白字与金属字不默认增强夜间发光。

所有 HEX、尺寸区间及摆放比例均为艺术/照片解释估计，未现场校色、量测或求解相机姿态。引用图仅作目视证据，照片和摄影师水印未打包为纹理；腾讯媒体库注明 editorial use only。本文件完成的是资料与制作输入，尚未构建或实机验收招牌。
