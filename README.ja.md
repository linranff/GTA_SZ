# ShenChengJi · 深城纪

**深圳を舞台に、ドライブと日常生活を楽しむブラウザーゲームのプロトタイプ。**

[English](README.md) · [简体中文](README.zh-CN.md) · **日本語**

[リリース v0.2](https://github.com/linranff/ShenChengJi/releases/tag/v0.2) · Babylon.js · TypeScript · Blender

藍色のコンセプトGTで湾岸を走り、街を歩き、小さな仕事を引き受け、ときには空から街並みを眺める。ShenChengJiは、深圳湾・南山・福田・羅湖の一部を凝縮し、行き来して遊べる都市エリアとして再構成したゲームです。

ゲーム内UIは現在、主に簡体字中国語です。3言語で提供しているのはドキュメントであり、ゲーム内の言語パックではありません。

![現在のゲームでの夜間ドライブ](docs/images/v0.2-night-driving.png)

## v0.2で楽しめること

- **3つのライティングモード：** 雲がまばらに浮かぶ青空、写真を思わせる夕景、天の川とほのかに照らされた薄雲のある夜空。湾の水面や道路の水たまりには、周囲の景色が映り込みます。
- **つながりを感じられる街並み：** 上空からも既存の建物の外観とマテリアルを表示し、細部や局所的な照明は見ているエリアに合わせて更新します。消灯したフロア、窓ごとの明かり、控えめな色のアクセントで、夜のスカイラインに奥行きを持たせています。
- **プレイヤーのGT：** 既存のコックピット、動作する計器、ブレーキランプの反射に加え、リアウイング、金属製の4本出しマフラー、HDR表現の冷白色ヘッドライトを追加しました。
- **好きな方法で探索：** ドライブ、徒歩、ドローン視点に対応。検索できる地図、ルートのプレビュー、ナビゲーション、手動運転に切り替えられる自動運転も利用できます。
- **街での仕事：** 配達・送迎・メンテナンスの依頼を繰り返し受注できます。アップグレード、キャラクターとの会話や選択肢、住まいのための貯金目標もあります。進行状況は使用中のブラウザーに保存されますが、ページを再読み込みすると、未完了の依頼は受注し直す必要があります。
- **複数のレイヤーで構成した都市：** OSM由来の道路と建物の輪郭、選定したランドマークのモデル、海岸の地形、橋、植生、ストリートファニチャー、一般車両、歩行者を組み合わせています。

![GTのリアウイングと4本出しマフラー](docs/images/v0.2-sport-gt.png)

画像は、実際に動作しているゲームから撮影した未加工のスクリーンショットです。本作はまだプロトタイプであり、交通や衝突判定は簡略化しています。建物の高さや外観には表現上の推定が含まれ、貯金目標を達成しても、モデル化された住居が解放されるわけではありません。深圳全域を測量精度で再現したものではありません。

## ローカルで起動する

**Node.js 24**、npm、Git LFS、WebGL2に対応したデスクトップブラウザーを使用してください。現在の表示確認には、macOS版Chromeを使用しています。

```sh
git lfs install
git clone --branch v0.2 https://github.com/linranff/ShenChengJi.git
cd ShenChengJi
git lfs pull
npm ci
npm run dev
```

Viteが表示するアドレスを開いてください。通常は `http://127.0.0.1:5173/` です。大きなモデル、HDR環境、画像は **Git LFS** に保存されています。ソースをダウンロードしても、実体の代わりにLFSポインターしか含まれていない場合、ゲームは動作しません。リポジトリが非公開の間は、アクセス権が必要です。

本番ビルドをプレビューするには、次を実行します。

```sh
npm run build
npm run preview -- --port 4173
```

長時間のプレイ中も安定して動作するよう、開発サーバーではホットリロードとポーリングを無効にしています。編集後は手動で再読み込みしてください。既存のアセットで遊ぶだけなら、Blenderや元の地形データのダウンロードは**不要**です。

## 操作

| 入力 | 操作 |
| --- | --- |
| W A S D / 矢印キー | 運転：加速、ステアリング、ブレーキ／後退 |
| Space | ハンドブレーキ |
| C | 追従・コックピット・遠景の運転カメラを切り替え |
| F | 車の近くで停止中に乗り降り／観察視点を終了 |
| V | 車を観察／もう一度押すと戻る |
| G | ドローン視点の開始／終了 |
| マウスドラッグ / ホイール | 観察視点で周囲を回り込む / ズーム |
| ドローン：W A S D / 矢印キー | 移動 / 視点の向きを変更 |
| ドローン：Q / E / Shift | 下降 / 上昇 / 高速移動 |
| ドローン：Shift + ドラッグ | 視点を平行移動 |
| M / Tab | 地図：検索、場所の選択、ナビゲーションや見学方法の選択 |
| L | 夕方 → 夜 → 昼の順に切り替え |
| J / E | シティジャーナルを開く / 停止中、近くの目標地点でインタラクト |
| H | クラクション |
| R | 車を近くの道路に戻す |
| Esc / P | メニューを閉じる、または一時停止 / フレームレートを表示 |

徒歩では、W A S Dで移動し、ドラッグまたは矢印キーで見回します。Shiftを押し続けると速く歩けます。自動運転中は、運転操作またはSpaceで手動運転に戻ります。一時停止メニューには効果音と音楽の設定があります。音声は最初のクリックまたはキー入力後に再生されます。

## 開発と検証

```sh
npm test
npm run build
```

v0.2のリリース候補は、**90件のテスト**と本番ビルドを通過しています。現在のスクリーンショットと短時間の性能測定は、[都市の品質とGTスポーツキット](docs/graphics/city-quality-sport-2026-09-06.md)に記録しています。この測定は、すべてのコンピューターや街の全域で安定したフレームレートを保証するものではありません。

ローカルサーバーの起動後、次のコマンドで最新の表示確認を再実行できます。

```sh
node scripts/check-distant-city.mjs http://127.0.0.1:5173/
node scripts/check-city-sport-details.mjs http://127.0.0.1:5173/
```

これらのスクリプトは現在、macOS版Chromeの実行ファイルパスを使用しています。画像と詳細な診断結果は `output/playwright/` 以下に生成され、ソースのチェックアウトには含まれません。

| 分野 | 主な入口 |
| --- | --- |
| ブラウザーアプリとシーン | `src/main.ts`、`src/city-world.ts` |
| 運転と都市生活のルール | `src/driving.ts`、`src/city-career.ts` |
| 基本の都市データとランドマークの追加データ | `public/city/city.json`、`public/city/landmark-detail.json` |
| 近距離のファサードのストリーミング | `src/city-facade-stream.ts` |
| GTのスポーツ装備 | `src/city-sport-details.ts` |
| Blender用メッシュヘルパー | `scripts/city_mesh.py` |

詳細なファサードは640 m単位のタイルでストリーミングします。1,050 m以内で先読みし、700 m以内で表示、1,500 mを超えるとアンロードします。基本の建物と道路はアセット全体を読み込みます。上空視点でも元の建物メッシュを保持し、視錐台カリングを使用します。移動中は、負荷の高い局所的な更新の頻度を抑えています。

アセットの再構築は別の作業フローです。再生成する前に、[アセットのビルドと配布](docs/资产重建与交付保护.md)、[ランドマークの配布](docs/landmarks/delivery.md)、[海岸の実装](docs/coastal/implementation.md)を確認してください。`npm run assets -- --plan` で実行予定のビルド計画を表示できます。ただし、全アセットのクリーンリビルドは、最初から最後まで通した検証がまだ済んでいません。`scripts/city_mesh.py` はインポート時にBlenderのシーンを初期化するため、通常のデータ確認にはインポートしないでください。
